About This Game

RUINS は「移動拠点」を押して凍てつく世界を渡るローグライクだ。 あなたは 3x3 のキューブを我が家として連れ歩き、凍原を一方向へ押し進む。 外は寒波前線に追われる片道の旅、中は拾った物を並べて暮らす異次元の空間だ。

本当の敵はモンスターではなく兵站だ。食料、体温、そして運べる重量。 遺跡を漁れば戦利品は増えるが、積むほど移動拠点は重くなり、一歩が遠くなる。 「何を残し、何を捨てるか」そのものが、旅の速さと生存を決める。

PILLAR 01

移動拠点を押して世界を渡る

3x3 のキューブが我が家。外は凍原を4方向へ押して進み、中は拾った物を並べて暮らす異次元の空間。積んだ物の重さがそのまま押しのコストになり、何を積み何を捨てるかが旅の速さを決める。

◈ 連れ歩く我が家（Kenshi の移動生活）
PILLAR 02

兵站とキャラバン交易が核

食料・体温・重量が常にのしかかる「生活の重み」。集落ごとの価格差を読んで積荷を組み替え、寒波に追われながら経路と引き際を選ぶ。補給線を回すこと自体が遊びになる。

◈ 身体で分かる生活の圧（CDDA）／開けた旅の交易（Sunless Sea）
PILLAR 03

豊富なアイテムの収集

遺跡・市街地・集落に多種多様な物が眠る。ありふれた物から希少な戦利品まで、漁って集めること自体が楽しい。使うか、売るか、持ち続けるか。重量制約の下で「何を残すか」が毎回の決断になる。

◈ 育つ大量パラメータの楽しさ（Elona）
PILLAR 04

前進のみが生、そして永続死

背後から寒波前線がゆるやかに迫り、呑まれた土地は凍てついて戻れない。後退は死、前進のみが生。もう一つ遺跡を襲えば戦利品は増えるが、死ねばランは終わる。引き際の見極めが核心。

◈ 片道踏破と喪失の重み（FTL / RimWorld）

Features

  • ターン制の移動拠点サバイバル ―― 拡張可能なキューブを押して凍原を渡る
  • 勝利状態を持たない ―― 死・凍結・餓死でランが終わり、到達距離が記録に残る
  • 兵站サバイバル ―― 食料・体温・重量が本当の制約
  • 豊富なアイテム収集 ―― ありふれた物から希少な戦利品まで漁って集める
  • 重量押し経済 ―― 積んだ物の重さが移動拠点を押すコストになる
  • キャラバン交易 ―― 集落ごとの価格差を読んで積荷を組み替える
  • 任意クエスト ―― 運搬・護衛を受けても、無視して前進してもよい
  • 2層ビルド ―― サイボーグ内蔵（電力共有）＋外付け装備
  • 使用ベース成長 ―― 使うほどスキルが永続的に育つ
  • 一方向ワールド ―― 西から東へ塗り潰される凍原を片道踏破する
  • ピクセルアートの凍てつく遺跡 ―― 青き氷晶と焚き火の温度
