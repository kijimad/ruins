# 物を投げて敵に当てる

## 背景

物の使い道に特化する方針では、物を増やすことと同じくらい、操作を増やすことが効く。同じ物でも操作ごとに別の使い道が生まれ、試せることが物の数と操作の数の掛け算で増える。今の操作は、調べる・置く・食べる・読む・使う・分解するの6つで、投げるが無い。

投げるが無いことで、次のことが起きている。

- 石と尖った石は、説明文で「投げると武器になる」と約束しているのに、使い道が無い
- 手榴弾・毒手榴弾・火炎手榴弾は `inflictsDamage` を持ち、「使う」と使った本人が傷つく。投げる物が自分に効く
- 持ち物画面の動詞の表には「投げるは後で足す」と書かれたままになっている

## 要件

- 投げられる物は、物の行に投げの欄を書いた物だけにする。性質は物の行の欄で表す方針どおり、欄を書けば投げられる
- 狙いは、射撃と同じく見えている敵から選ぶ。射程・射線・命中・ダメージは射撃の仕組みを使う
- 投げるほど上達する投擲のスキルを足す
- 消費物は投げると無くなる。消費物でない物は、当たっても外れても、狙った敵の足元に落ち、拾い直せる
- 手榴弾は狙った敵1体に当てる。使った本人が傷つく効果は消す
- 持ち物画面に「投げる」の動詞を足し、ダンジョンからも直接呼べる

## 設計

### 物の行の投げの欄

```cue
// 投げて当てる攻撃。持つ物は持ち物画面の投げるに出る
#Throw: {
	damage!:   #BaseDamage
	accuracy!: #Accuracy
}

#Item: {
	// ...今の欄
	throw?: #Throw
}
```

```go
// Throw は投げて当てる攻撃の性質。攻撃の種類は投擲に固定する
type Throw struct {
	Damage   int
	Accuracy int
}
```

`Throw` は攻撃の値の型 `gc.Attacker` を満たし、攻撃の種類は `throw`、属性は無し、攻撃回数は1にする。投げる行動は、射撃と同じ命中とダメージの計算 `applyAttackDamage` にこの値を渡す。

物ごとの値は次の案にする。

| 物 | 重さ | damage | accuracy | 消費物 |
|---|---|---|---|---|
| 石 `stone` | 1 kg | 6 | 70 | いいえ |
| 尖った石 `sharp_stone` | 300 g | 5 | 80 | いいえ |
| 手榴弾 `grenade` | 400 g | 20 | 75 | はい |
| 毒手榴弾 `poison_grenade` | 400 g | 15 | 75 | はい |
| 火炎手榴弾 `flame_grenade` | 400 g | 25 | 75 | はい |

手榴弾3種の damage は、今の `inflictsDamage` の値をそのまま移す。

### 攻撃の種類と投擲のスキル

攻撃の種類の列挙に `throw` を足し、`attackTypes` に行を1つ足す。遠距離の攻撃として、射程と命中の落ち方を持つ。

```toml
[[attackTypes]]
  accuracy = "throw_accuracy"
  damage = "throw_damage"
  id = "throw"
  injury = "fracture"
  maxRange = 6
  name = "Throwing"
  optimalRange = 3
  penaltyPerTile = 10
  range = "ranged"
  skill = "throwing"
```

射程は弓より短くする。弓は最適射程が4、最大射程が10。

スキルの列挙に `throwing`、熟練の列挙に `throw_damage` と `throw_accuracy` を足し、`skills` に行を足す。伸び方は弓にそろえる。

```toml
[[skills]]
  ability = "sen"
  category = "ranged"
  effect = "Increases throwing damage and accuracy"
  gainedBy = "Raised by throwing items at enemies"
  id = "throwing"
  name = "Throwing"
  summary = "Technique for throwing items"
  [[skills.proficiencies]]
    id = "throw_damage"
    perLevel = 5
  [[skills.proficiencies]]
    id = "throw_accuracy"
    perLevel = 3
```

### 投げる行動

```go
// ThrowParams は投げる行動のパラメータ
type ThrowParams struct {
	Item   ecs.Entity // 投げる物
	Target ecs.Entity // 狙う敵
}
```

- 行動の種類に `BehaviorThrow` を足し、`internal/activity/throw.go` に `ThrowBehavior` を置く
- Validate は、物が背負い袋にあり `Throw` を持つこと、狙う敵が生きていること、射程と射線を射撃と同じ関数で確かめる
- DoTurn は、射撃と同じ命中の補正と `applyAttackDamage` で当てる。そのあと、消費物なら1つ減らし、消費物でなければ1つを狙った敵の足元へ移す。移すのは `lifecycle.MoveMembersToField`
- 狙える敵の判定は、射撃の `CanShootTarget` にならい `CanThrowTarget` を置く

### 狙いを選ぶ画面

射撃の画面 `ShootingState` は、見えている敵を絞り、Tab で切り替え、Enter で撃つ。投げるも同じ流れなので、狙える敵の判定と実行だけを差し替えられるように画面を共有する。命中率の表示も、投げる物の値で計算する。

### 持ち物画面の動詞

動詞の表に「投げる」を足す。キーは Shift+t。対象は `Throw` を持つ物で、実行すると狙いを選ぶ画面を重ねる。

### 自傷の効果を消す

`inflictsDamage` の欄、`InflictsDamage` コンポーネント、使うの効果の組の `damageEffect` を消す。手榴弾3種は投げの欄だけを持つ。消費物の欄は「投げると無くなる」の意味で残す。

`schema.cue` の「食べる・使うの効果を持つ物は消費物」の一覧から `inflictsDamage` を外す。

### 使い道の統計

`internal/raw/item_uses_test.go` の「投げる」の列を、`InflictsDamage` でなく `Throw` の有無で数える。石と尖った石が加わり、3から5になる。

## 採用しなかった方法

- **どの物も投げられ、重さから威力を導く**: 布や紙まで武器になり、重さだけでは尖った石と石の違いを出せない
- **既存のスキルに相乗りする**: 格闘や弓の熟練で投げると、何で上達したかの意味がずれる
- **手榴弾の爆風の範囲まで入れる**: 範囲の決め方と味方への巻き込みを決める必要があり、最初の段が大きくなる。単体に当てる形で投げるの仕組みを先に通す
- **マスを自由に狙う**: カーソルでマスを選ぶ画面を一から作ることになる。音で敵を引く、火にくべる、などマスを狙う理由ができたときに足す
- **マーカー `Throwable` を付ける**: 投げの欄に値が要るので、値を持つ欄そのものを性質にする
