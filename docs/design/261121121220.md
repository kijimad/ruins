# 物を投げて敵に当てる

## 背景

物の使い道に特化する方針では、物を増やすことと同じくらい、操作を増やすことが効く。同じ物でも操作ごとに別の使い道が生まれ、試せることが物の数と操作の数の掛け算で増える。今の操作は、調べる・置く・食べる・読む・使う・分解するの6つで、投げるが無い。

投げるが無いことで、次のことが起きている。

- 石と尖った石は、説明文で「投げると武器になる」と約束しているのに、使い道が無い
- 手榴弾・毒手榴弾・火炎手榴弾は `inflictsDamage` を持ち、「使う」と使った本人が傷つく。投げる物が自分に効く
- 持ち物画面の動詞の表には「投げるは後で足す」と書かれたままになっている

## 要件

- 投げられる物は、物の行に投げの欄を書いた物だけにする。性質は物の行の欄で表す方針どおり、欄を書けば投げられる
- 狙いは、射撃と同じく見えている敵から選ぶ。射程・射線・命中・ダメージは射撃の仕組みを使う
- 投げるほど上達する投擲のスキルを足す
- 消費物は投げると無くなる。消費物でない物は、当たっても外れても、狙った敵の足元に落ち、拾い直せる
- 手榴弾は狙った敵1体に当てる。使った本人が傷つく効果は消す
- 持ち物画面に「投げる」の動詞を足し、ダンジョンからも直接呼べる

## 設計

### 物の行の投げの欄

```cue
// 投げて当てる攻撃。持つ物は持ち物画面の投げるに出る
#Throw: {
	damage!:   #BaseDamage
	accuracy!: #Accuracy
}

#Item: {
	// ...今の欄
	throw?: #Throw
}
```

```go
// Throw は投げて当てる攻撃の性質。攻撃の種類は投擲に固定する
type Throw struct {
	Damage   int
	Accuracy int
}
```

`Throw` は攻撃の値の型 `gc.Attacker` を満たす。欄に無い値は次のように固定する。

| メソッド | 値 |
|---|---|
| `GetAttackCategory` | `throw` |
| `GetElement` | 無し `NONE` |
| `GetAttackCount` | 1 |
| `GetCost` | 1。持ち物の詳細の「Attack cost」にも出る |
| `GetTargetType` | 敵1体。`ENEMY`・`SINGLE` |

投げる行動は、射撃と同じ命中とダメージの計算 `applyAttackDamage` にこの値を渡す。

物ごとの値は次の案にする。

| 物 | 重さ | damage | accuracy | 消費物 |
|---|---|---|---|---|
| 石 `stone` | 1 kg | 6 | 70 | いいえ |
| 尖った石 `sharp_stone` | 300 g | 5 | 80 | いいえ |
| 手榴弾 `grenade` | 400 g | 20 | 75 | はい |
| 毒手榴弾 `poison_grenade` | 400 g | 15 | 75 | はい |
| 火炎手榴弾 `flame_grenade` | 400 g | 25 | 75 | はい |

手榴弾3種の damage は、今の `inflictsDamage` の値をそのまま移す。これまでの自傷は固定の値をそのまま与えていたが、投げると `formula.Damage` で感覚の値・スキルの倍率・防御が掛かる。遠距離武器の damage は 4〜34 に分布し、火炎手榴弾の 25 は上のほうになる。消費物なので高めにしているが、実装後に手触りで調整する。命中は基準の 80 からの差が補正になるので、石の 70 は -10、尖った石の 80 は ±0 になる。

### 攻撃の種類と投擲のスキル

攻撃の種類の列挙に `throw` を足し、`attackTypes` に行を1つ足す。遠距離の攻撃として、射程と命中の落ち方を持つ。

```toml
[[attackTypes]]
  accuracy = "throw_accuracy"
  damage = "throw_damage"
  id = "throw"
  injury = "fracture"
  maxRange = 6
  name = "Throwing"
  optimalRange = 3
  penaltyPerTile = 10
  range = "ranged"
  skill = "throwing"
```

射程は弓より短くする。弓は最適射程が4、最大射程が10。

ブーメランと手裏剣は、今は弓の攻撃の種類 `bow` を持つ、装備して撃つ武器になっている。どちらも投げる武器なので、攻撃の種類を `throw` に移し、投擲のスキルで上達するようにする。装備して撃つ形と、ブーメランが手元に戻る挙動はそのまま保つ。物を手放す投げる行動とは別に、射撃の経路で使う。射程は弓より短くなる。

スキルの列挙に `throwing`、熟練の列挙に `throw_damage` と `throw_accuracy` を足し、`skills` に行を足す。伸び方は弓にそろえる。

```toml
[[skills]]
  ability = "sen"
  category = "ranged"
  effect = "Increases throwing damage and accuracy"
  gainedBy = "Raised by throwing items at enemies"
  id = "throwing"
  name = "Throwing"
  summary = "Technique for throwing items"
  [[skills.proficiencies]]
    id = "throw_damage"
    perLevel = 5
  [[skills.proficiencies]]
    id = "throw_accuracy"
    perLevel = 3
```

### 投げる行動

```go
// ThrowParams は投げる行動のパラメータ
type ThrowParams struct {
	Item   ecs.Entity // 投げる物
	Target ecs.Entity // 狙う敵
}
```

- 行動の種類に `BehaviorThrow` を足し、`internal/activity/throw.go` に `ThrowBehavior` を置く
- Validate は、物が背負い袋にあり `Throw` を持つこと、狙う敵が生きていること、射程と射線を射撃と同じ関数で確かめる
- DoTurn は、狙った敵の座標を先に取ってから、射撃と同じ命中の補正と `applyAttackDamage` で当てる。そのあと、消費物なら1つ減らし、消費物でなければ1つを先に取った座標へ移す。移すのは `lifecycle.MoveMembersToField`。座標を先に取るので、倒した敵の死亡の処理に頼らない
- 狙える敵の判定は、射撃の `CanShootTarget` にならい `CanThrowTarget` を置く

### 狙いを選ぶ画面

射撃の画面 `ShootingState` は、見えている敵を絞り、Tab で切り替え、Enter で撃つ。投げるも同じ流れなので画面を共有し、射撃と投げるで違う部分をインターフェースに切り出す。

```go
// targetAction は敵を狙う画面で、射撃と投げるで違う部分
type targetAction interface {
	canTarget(world w.World, actor, target ecs.Entity) bool
	hitRate(world w.World, actor, target ecs.Entity) int
	execute(world w.World, actor, target ecs.Entity) error
	// infoLines は情報パネルの行。射撃は装弾数など武器の状態、投げるは投げる物の名前と残りの数
	infoLines(world w.World, actor ecs.Entity) []string
}
```

射撃は装備中の武器を、投げるは投げる物の entity を持つ。今の `checkFireWeaponStatus` と `drawWeaponInfo` は射撃の実装の側へ移す。

### 持ち物画面の動詞

動詞の表に「投げる」を足す。キーは Shift+t。対象は `Throw` を持つ物で、実行すると狙いを選ぶ画面を重ねる。

「使う」の t は今は Shift の指定が無く、Shift+t でも反応する。置く d と分解する D の組と同じく、「使う」を Shift 無しに限り、投げるを Shift 付きにする。持ち物画面の動詞の表と、ダンジョンのキーの束縛の両方を直す。ダンジョンのキーの束縛は、全行の条件が互いに重ならないことを前提にしている。

アクション `ActionVerbThrow` と、ダンジョンから動詞画面への受け渡しは、すでにある。足すのはキーの束縛だけになる。

### 自傷の効果を消す

`inflictsDamage` の欄、`InflictsDamage` コンポーネント、使うの効果の組の `damageEffect` を消す。手榴弾3種は投げの欄だけを持つ。消費物の欄は「投げると無くなる」の意味で残す。

手榴弾3種の消費物の欄は、今は `targetNum = "ALL"` で、単体に当てる投げると食い違う。`targetNum` を `SINGLE` に直す。消費物の欄の対象と使える場面は、投げるでは読まない。

`schema.cue` の「食べる・使うの効果を持つ物は消費物」の一覧から `inflictsDamage` を外す。

### 使い道の統計

`internal/raw/item_uses_test.go` の「投げる」の列を、`InflictsDamage` でなく `Throw` の有無で数える。石と尖った石が加わり、3から5になる。

## 採用しなかった方法

- **どの物も投げられ、重さから威力を導く**: 布や紙まで武器になり、重さだけでは尖った石と石の違いを出せない
- **既存のスキルに相乗りする**: 格闘や弓の熟練で投げると、何で上達したかの意味がずれる
- **手榴弾の爆風の範囲まで入れる**: 範囲の決め方と味方への巻き込みを決める必要があり、最初の段が大きくなる。単体に当てる形で投げるの仕組みを先に通す
- **マスを自由に狙う**: カーソルでマスを選ぶ画面を一から作ることになる。音で敵を引く、火にくべる、などマスを狙う理由ができたときに足す
- **マーカー `Throwable` を付ける**: 投げの欄に値が要るので、値を持つ欄そのものを性質にする
- **ブーメランと手裏剣を投げの欄で投げる物にする**: 投げると手放すので、手元に戻るブーメランの挙動と食い違う。装備して撃つ武器のまま、攻撃の種類だけを投擲に移す
- **ブーメランと手裏剣を弓のまま残す**: 投げる武器なのに弓の熟練で上達し、何で上達したかの意味がずれる
