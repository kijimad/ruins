# 区域を一般化し、大きさの違う街と研究所の敷地を置く

## 背景

オーバーワールドの市街地は、複数のチャンクにまたがる建物の集まりとして作られている。参考 codebase: `internal/overworld/urban.go`。

- 市街地の大きさは各辺2〜3チャンクに固定されている。小さな集落も大きな都市も無く、どの街も同じ規模に見える。
- 研究所 lab は、市街地の都心に建つ1棟の施設でしかない。実際の研究所は、実験棟・講義棟・管理棟・閉鎖区画のような複数の建物が塀の中に集まった敷地になる。1棟では表せない。
- 施設の多様化 261108165219 の3段目で、軍基地と発電施設を「市街地の外の単独の大きな施設」として置くと決めている。研究所の敷地と同じく、複数の建物の集まりになる。

市街地と研究所の敷地は、どちらも「チャンクを並べた区画に、地区ごとの施設を1棟ずつ建てる」という同じ形をしている。違うのは、大きさ、縁の作り、どの地区をどこに置くか、の3つだけになる。

建物1棟は施設の絵で描く。設計 doc 261113010103 の仕組みをそのまま使う。

## 要件

1. 市街地の大きさを区域ごとに変える。小さな町から大きな街まで出る。
2. 研究所を、複数の建物が塀の中に集まった敷地として置く。敷地は帯の全幅に広がり、縦に長い。
3. 研究所の敷地の中は、管理棟・講義棟・実験棟・閉鎖区画のように場所で役割が分かれる。奥ほど危険になる。
4. 軍基地や発電施設を、同じ仕組みに区域の種類を足すだけで置けるようにする。
5. 生成は今と同じく、run の seed とチャンクの座標の純関数のままにする。近くのチャンクを生成せずに、どの区域のどこかを決められる。

## 設計

### 区域

複数のチャンクにまたがる施設の集まりを「区域」と呼ぶ。市街地も研究所の敷地も区域の1種類にする。区域の種類は raw の行で定義する。

```cue
// 区域の種類。複数のチャンクにまたがる施設の集まり
#District: {
	id!: #EntityID
	// 大きさの候補。区域ごとに重みで1つ選ぶ
	sizes!: [...#DistrictSize] & [_, ...]
	// 当選の間隔と最小の空き。#Placement と同じ意味
	spacing!:    int & >=1
	separation!: int & >=0
	// 縁の作りと、地区の割り振り方
	layout!: #DistrictLayout
}

// 区域の大きさの候補。w が帯の列数を超えるときは帯の全幅に詰める
#DistrictSize: {
	w!:      int & >=1
	h!:      int & >=1
	weight!: int & >=1
}

// town は各チャンクの北辺と西辺に街路を敷き、中心を都心にする。
// campus は外周に塀を巡らせて南北に門を開け、南の門から奥へ向かって地区を並べる
#DistrictLayout: "town" | "campus"
```

```toml
[[districts]]
id = "town"
spacing = 7
separation = 2
layout = "town"
sizes = [
  { w = 2, h = 2, weight = 6 },
  { w = 3, h = 3, weight = 4 },
  { w = 4, h = 3, weight = 2 },
  { w = 5, h = 5, weight = 1 },
]

[[districts]]
id = "lab_campus"
spacing = 30
separation = 4
layout = "campus"
sizes = [{ w = 7, h = 6, weight = 1 }, { w = 7, h = 8, weight = 1 }]
```

- 1行が1種類の区域になる。数値は例で、着手時に調整する。
- 地区の割り振り方は種類ごとにコードで持ち、`layout` の列挙で選ぶ。switch は exhaustive にして、列挙を足したときの漏れを lint で止める。

### 大きさを先に決め、位置を後から引く

今の市街地は、リージョンの当選位置を引いたあとで大きさを決める。そのため、あるチャンクを含む市街地を探すには、大きさの上限ぶん北西を走査する必要がある。

区域では順番を逆にする。リージョンごとに、まず大きさを引き、余った縦の範囲から位置を引く。

```go
// districtRegion は区域の1つの当選。帯ローカルのチャンク座標で、左上 anchor から w×h 広がる
type districtRegion struct {
	district string
	anchor   consts.Coord[consts.Chunk]
	w, h     consts.Chunk
}

// regionOf はリージョン ry の区域を返す。大きさを重みで引き、区域がリージョンの縦の範囲
// [ry*spacing, (ry+1)*spacing - separation) に収まるよう位置を引く
func (d districtKind) regionOf(runSeed uint64, ry, cols consts.Chunk) districtRegion

// districtAt は c を含む区域と、区域の中の位置を返す。c の属するリージョンだけを見ればよい
func districtAt(runSeed uint64, c consts.Coord[consts.Chunk], cols consts.Chunk) (districtRegion, consts.Coord[consts.Chunk], bool)
```

- 区域は自分のリージョンの縦の範囲からはみ出さない。チャンク c を含みうる区域は、c の行が属するリージョンの1つだけになり、走査が要らない。
- raw の検証で、各区域の全ての大きさの h が `spacing - separation` 以下であることを確かめる。

### 区域どうしの優先

種類の違う区域は、互いのリージョンを知らずに当選するので重なりうる。種類に優先順を付け、重なったら優先の低い区域を丸ごと出さない。優先は研究所の敷地のような珍しい区域を上にする。

- 低い区域を丸ごと消すのは、街路の途中に塀が刺さった半端な街を出さないため。
- 優先の高い区域がどこにあるかは、その種類のリージョンを数個引けば決まる。生成せずに判定できる。
- 集落は今と同じく区域に譲る。

### 地区と施設

施設の行の `zones` が、どの地区に建つかを決める仕組みはそのまま使う。地区の列挙に研究所の敷地の地区を足す。

```cue
#Zone: "downtown" | "residential" | "industrial" | "campus_gate" | "campus_inner" | "campus_quarantine"
```

| 地区 | 場所 | 建つ施設の例 |
|---|---|---|
| `campus_gate` | 南の門に面した列 | 管理棟 |
| `campus_inner` | 中ほどの列 | 講義棟、実験棟 |
| `campus_quarantine` | 北の奥の列 | 閉鎖区画 |

- プレイヤーは南から北へ進むので、南の門から入り、奥へ進むほど危険になる。閉鎖区画の敵の表を一番強くする。
- 今の `lab` は、`lab_admin`・`lab_lecture`・`lab_experiment`・`lab_quarantine` の4行に分ける。それぞれに施設の絵を描く。市街地の都心からは研究所を外す。
- 町では、大きい町ほど都心を広くする。中心からのチェビシェフ距離が大きさに応じた閾値以下のチャンクを都心にする。

### 研究所の敷地の縁

敷地は帯の全幅に広がるので、北へ進む道を塞ぐ。南と北の両方に門を開け、門から門へ縦に抜ける構内の道を通す。

- 外周に塀を巡らせる。塀は区画の外側の街路の帯に置く。東と南の辺には街路が無いので、建物の区画の外側1列に置く。施設の絵は外周1マスを屋外の地面で描く約束にし、施設の絵のテストで確かめる。
- 構内の道は、各チャンクの北辺と西辺の街路をそのまま使う。
- 帯をまたいで集落を結ぶ道は、敷地に当たったら門へ寄せる。

### 地図

市街地と同じく、区域のチャンクは施設の地図記号で表示する。新しい施設の行ごとに `mapGlyphs` を足す。

## 採用しなかった方法

- **研究所を市街地の地区の1つにする。** 一番安いが、塀と門、場所で変わる危険度のような敷地としての作りが出せない。
- **研究所の敷地を1枚の大きな絵で描く。** チャンクごとに独立に生成する今の仕組みと合わず、描く量も大きい。
- **今の走査窓を大きさの上限まで広げる。** 大きな区域を足すほど、チャンクごとの走査が大きさの上限の2乗で増える。大きさを先に引けば走査が要らない。
- **区域の種類ごとに Go のコードで定義する。** 大きさや間隔の調整のたびにコードを直すことになる。数値は raw の行に置き、振る舞いの違いだけを `layout` の列挙でコードに持つ。
- **地区の割り振り方を raw にデータで書く。** 割り振り方は町と敷地の2通りで、規則の表現を作るほうが重い。種類が増えて形が似てきたら考える。
- **重なった区域の低い側を、重なったチャンクだけ消す。** 街路の途中に塀が刺さった半端な街になる。

## コメント

- 区域の大きさに幅を持たせ、研究所や軍基地のような特殊な施設を複数マスの塊として置く作りは、既存のローグライクの地図生成にもある。着想は参考程度で、仕組みは ruins の区域と施設の絵だけで完結させる。
- 1段目で町を区域へ移すと、同じ seed でも市街地の位置と大きさが変わる。未リリースなので考慮しない。
