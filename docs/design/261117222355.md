# 初期スポーンの避難所

## 背景

新しいゲームは、帯の中央の列・開始の行のチャンクの真ん中に一番近い歩けるマスから始まる。参考 codebase: `internal/overworld/driver.go` の `startInitialBand`。開始チャンクに何があるかは見ていないので、置かれる場所はチャンクの分類のくじしだいである。

seed を1000個回して開始チャンクの種別を数えると、次のようになった。

| 開始チャンク | 割合 |
|---|---|
| 荒れ地 | 41% |
| 研究所の区域 | 26% |
| 軍の基地 | 11% |
| 町 | 10% |
| 発電所 | 7% |
| 農場 | 3% |
| 点在ランドマーク | 3% |

研究所の区域は横がいつも帯の全幅の7チャンクで、縦も6〜8チャンクあり、開始の行の入る最初のリージョンに置かれやすい。そのため、最初から研究所の中で始まることが多い。開始地点は、くじの結果で研究所の奥にも荒れ地の真ん中にもなり、最初の数ターンの体験がそろわない。

初期の持ち物は、プレイヤーの行と職業の `startingItems`・`startingEquips` で持たせている。地上に置かれる物は無い。

## 要件

- 新しいゲームは、必ず開始の避難所の中から始まる。
- 避難所は、文字でなく、物の置き方で世界を語る。荒らされた棚、残された物、入口の外の弱い敵など。
- 避難所は、最初の手順の練習を兼ねる。焚き火を起こす、怪我を手当てする、食べる、寝る、戦う、の道具が手の届くところにある。
- 開始チャンクに研究所や軍の基地のような区域が重なっても、半端な区域を作らない。
- 生成は今までどおり、位置と seed の純関数のままにする。

## 設計

### 開始チャンクを避難所の専用の種別にする

チャンクの分類に、避難所の種別を足す。開始チャンクは必ずこの種別になり、ほかのどの地物より優先する。

```go
const (
	chunkWasteland  chunkType = "wasteland"
	chunkSettlement chunkType = "settlement"
	chunkUrban      chunkType = "urban"
	chunkLandmark   chunkType = "landmark"
	chunkShelter    chunkType = "shelter" // 開始の避難所
)
```

開始チャンクは、帯の中央の列 `cols/2` と開始の行 `SpawnChunkY` で決まる。どちらも帯の形から決まり、seed に依らないので、分類は位置の純関数のままである。

区域が開始チャンクに重なるときは、その区域を丸ごと出さない。区域どうしの重なりを `overlapsAny` で丸ごと外しているのと同じ扱いで、塀や街路の途中に避難所が刺さった半端な区域を作らない。

### 避難所は手描きの施設の絵で作る

避難所は施設の1つとして、raw の `facilities` に行を持ち、手描きの絵とパレットで作る。避難所の候補は、ランドマークと同じく、施設の行を指して重みを持つ行にする。

```cue
// 開始チャンクに置く避難所の候補
#StartShelter: {
	// 施設の id。施設の絵の facility が指す
	id!:    #EntityID
	id_ref: _facilityIDs[id] @rawgen(-)
	// 開始チャンクでこの避難所を引く重み
	weight!: int32 & >=1
}

#Raws: {
	startShelters?: [...#StartShelter]
}
```

```toml
[[facilities]]
id = "shelter_bunker"
enemyTable = "shelter_enemies"
zones = []

[[startShelters]]
id = "shelter_bunker"
weight = 1
```

開始チャンクの地物は、避難所の候補を seed で引き、絵をチャンクの真ん中に置く。施設の絵の置き方 `spawnFacility` と、敵・戦利品・収納の中身の引き方は、施設と同じものを使う。

### 中身はパレットで置く

避難所の中身は、パレットの置物・床の戦利品・敵で置く。新しいコードは要らない。

| 目的 | 置く物 | パレットの欄 |
|---|---|---|
| 焚き火の練習 | 焚き火の跡、薪、火種 | `props`・`items` |
| 手当ての練習 | 包帯、薬 | `items` |
| 食べる・寝る | 食料、寝袋 | `items`・`props` |
| 戦う | 簡単な武器 | `items` |
| 世界を語る | 荒らされた棚、倒れた家具、入口の外の弱い敵 | `props`・`beings`・施設の `enemyTable` |

### 開始位置は絵の真ん中にする

避難所の絵をチャンクの真ん中に置き、絵の真ん中を床にする。今の「チャンクの真ん中に一番近い歩けるマス」がそのまま避難所の中になるので、開始位置の印の欄は足さない。キューブも、今までどおりプレイヤーの近くの歩けるマスに置く。

## 採用しなかった方法

- **区域を残し、開始チャンクだけを避難所に置き換える**: 研究所の敷地の中に避難所が入り、塀や街路の途中に避難所が刺さる。半端な区域を作らない今の原則に反する。
- **区域を開始地点から数チャンク離す**: 最初は荒れ地に囲まれ、少し歩くと建物に着く。ただ、区域の置き方に開始地点の特例を足すことになり、避難所を置く目的の「最初の体験をそろえる」とは別の問題である。
- **絵に開始位置の印を置く**: マスに開始位置の欄を足す必要がある。絵を真ん中に置けば、今の開始位置の決め方で避難所の中に立てる。
- **初期の持ち物を増やす**: 持ち物は職業の行で決まり、物の置き方で世界を語ることも、拾う練習もできない。
- **開始チャンクの特例を地物でなくドライバに置く**: 開始のときだけ避難所を置くと、チャンクの中身が位置と seed だけで決まらなくなる。地図の記号やエリア名も分類から引いているので、分類と地物に置けば、地図と実体が食い違わない。

## コメント

- 避難所の中身の具体的な配置と、敵の種類は、絵を描きながら決める。
- 避難所の候補は最初は1つで始め、絵を足すたびに `startShelters` に行を足す。
