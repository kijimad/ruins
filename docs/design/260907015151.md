# WASM は体験版としてセーブ・ロードをビルドタグで機構ごと外す

## 背景

WASM 版は体験版とし、セーブ・ロードを持たせない。ブラウザの localStorage は quota が小さく
永続性も保証しづらいので、体験版では保存機能を初めから外す方針。単に UI を隠すのでなく、
ビルドタグで機構ごと WASM バイナリから外し、save パッケージへの依存を断つ。

## 要件

- WASM ビルドではメインメニューの「ロード」とダンジョンメニューの「セーブ」を出さない。
- WASM ビルドの依存グラフから `internal/save` を外す。dead branch でも参照を残さない。
- デスクトップの挙動は不変。既存のメニュー・テスト・VRT golden はそのまま通す。
- 分割は既存の `internal/save` の `//go:build js && wasm` / `//go:build !js || !wasm` 慣習に合わせる。

## 設計

### save 結合コードをプラットフォーム別ファイルへ隔離する

`const bool` フラグで `if enabled { NewSaveMenuState }` と書くと、WASM の dead branch でも
`NewSaveMenuState` → `save` を参照し、機構がバイナリに残る。そこで save を参照するコードを
デスクトップ限定ファイルへ移し、WASM 側では symbol ごと存在させない。

```go
// saveload_desktop.go (//go:build !js || !wasm)
func loadMainMenuItem(world w.World) (mainMenuItem, bool) // ロード項目を返す, ok=true
func dungeonSaveMenuChoice(world w.World) (Choice, bool)  // セーブ項目を返す, ok=true
// NewSaveMenuState / NewLoadMenuState / loadSlotChoice / formatSaveSlotLabel /
// newResumeStateFactory / backChoice も全てここへ移す

// saveload_wasm.go (//go:build js && wasm)
func loadMainMenuItem(_ w.World) (mainMenuItem, bool) { return mainMenuItem{}, false }
func dungeonSaveMenuChoice(_ w.World) (Choice, bool)  { return Choice{}, false }
// save は import しない
```

メニュー構築側は採否を問うだけにする。

```go
if item, ok := loadMainMenuItem(world); ok { items = append(items, item) }        // main_menu.go
if c, ok := dungeonSaveMenuChoice(world); ok { choices = append(choices, c) }      // factories.go
```

### save パッケージの WASM 実体を無保存スタブにする

ゲーム本体は WASM で save を参照しないが、`go build ./...` はパッケージ単体をビルドするので、
`save/wasm.go` のプラットフォーム別メソッドは残す。ただし localStorage 保存は載せず、呼ばれても
永続化しないスタブにする。体験版=保存無効の意図をパッケージ層でも明示する。

## 変更箇所

| ファイル | 変更内容 |
|---|---|
| `internal/states/saveload_desktop.go` | 新設。save 結合の UI・ファクトリを集約。ロード/セーブ項目の採否関数を提供 |
| `internal/states/saveload_wasm.go` | 新設。採否関数が false を返す空実装。save を import しない |
| `internal/states/factories.go` | save/load 群を移設。`save`・`logger` import 除去。ダンジョンメニューを採否関数経由へ |
| `internal/states/main_menu.go` | ロード項目を採否関数経由の条件追加へ |
| `internal/save/wasm.go` | localStorage 保存を無保存スタブへ置換 |
| `internal/save/doc.go` | wasm.go の責務記述を更新 |

## 採用しなかった方法

- **const bool フラグで UI だけ隠す**: dead branch が save を参照し続け、WASM バイナリに機構が残る。
  「機構ごと消す」を満たさないので不採用。
- **save パッケージ全体をデスクトップ限定にする**: WASM で全ファイルがビルド制約で除外され、
  `go build ./...` が「build constraints exclude all Go files」で落ちる。スタブを残して回避する。
- **テストファイルにビルドタグを付ける**: デスクトップでしか走らないテストが desktop 限定 symbol を
  参照するのは既存の `save_integration_test.go` と同じ許容範囲。WASM でテストはビルドしないため不要。

## コメント

体験版の保存無効は、UI を隠すのでなく依存を断つことで表す。WASM ビルドの `internal/states` は
`internal/save` に依存しなくなり、機構ごとバイナリから外れる。デスクトップは無変更で、既存テストと
golden はそのまま通る。剥ぎ取りの検証は `GOOS=js GOARCH=wasm go list -deps .` に save が出ないことで行う。
