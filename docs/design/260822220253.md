# 気候生存: 前線を廃し、常時の寒さと吹雪と資源枯渇で自主移動を促す

## 背景

現状の気候圧力は寒波前線 `worldstream.Front` ただ1本に集約されている。幅を持つ極低温ゾーンが総ターン数に応じて東進し、居座るとプレイヤーを飲む。破棄と進入不可ラインもこの前線に統合されている。前線は「後ろから押す強制移動」であり、これがゲーム唯一の実効的な圧になっている。

問題は2つある。第一に、前線以外のペナルティが弱く、プレイヤーの行動を狭めていない。屋外での探索や滞在にコストが無く、前線から離れていれば自由に振る舞える。第二に、移動が前線による強制であってプレイヤーの意思でない。押されて動くので agency が薄い。

そこで気候モデルを The Long Dark 型へ移す。前線を廃し、世界を常時かなり寒くして全屋外行動に暖コストを課す。加えて周期的な吹雪でほぼ外出不可能な窓を作る。移動は強制でなく、局所資源の枯渇を避けるための自主的なものにする。左へ戻れない制約だけは残し、枯れた土地の再利用を封じて前進を担保する。

この doc は spawn の危険度軸を扱う [260822014350](260822014350.md) とは別軸を扱う。危険度は敵とアイテムの湧きを、気候は温度と生存を扱う。両者は直交するが、後述のとおり合成すると相互に効く。

## 要件

**Hard**

- 寒波前線を廃す。総ターン数に応じた強制的な空間押し出しをやめる。
- 常時の寒さが全屋外行動に暖コストを課し、だらだらした探索や滞在を成立させない。
- 局所資源は有限かつ非再生で、枯渇が東進の誘因になる。強制でなく誘因で動かす。
- 左へは戻れない。破棄と進入不可の境界を前線から切り離して存続させる。
- 吹雪は予告つきの周期イベント。窓のあいだ屋外はほぼ致死。退避先は既存の建物または野外の焚き火とし、新規の建設は要求しない。
- 破綻は即死でなく、凍傷を経てペナルティが累積する。身体システムへ接続する。
- 気候は決定論の純関数で導く。位置と総ターン数から決まり、位置そのものは保存しない。

**Soft**

- 危険度軸と合成し、生存のためにより危険な東へ引かれる緊張を作る。
- 予告なし逃げ場なしの理不尽な凍死を作らない。吹雪は必ず退避可能な余地とともに来る。

## 設計

### 気候の合成

温度は2層の合成にする。常時の底冷え ambient と、周期的な吹雪 blizzard を重ねる。どちらも位置と総ターン数の純関数で、`worldstream.FrontAt` が保存不要だった設計思想を継ぐ。

```go
// ClimateConfig はランごとに固定する気候パラメータ。総ターン数と併せれば現在の気候を復元できる。
type ClimateConfig struct {
	// AmbientColdness は屋外の底冷え。暖の基準減少レートを決める
	AmbientColdness int
	// BlizzardPeriodTurns は吹雪1周期のターン数
	BlizzardPeriodTurns consts.Turn
	// BlizzardDurationTurns は吹雪が居座るターン数。周期のうちこの分だけ極寒
	BlizzardDurationTurns consts.Turn
	// BlizzardWarnTurns は吹雪到来の予告を出すリードタイム
	BlizzardWarnTurns consts.Turn
}

// Climate は総ターン数時点の気候。IsBlizzard は吹雪の窓の内側か、TurnsToBlizzard は次の吹雪までの残り。
type Climate struct {
	Coldness       int
	IsBlizzard     bool
	TurnsToBlizzard consts.Turn
}

// ClimateAt は総ターン数から気候を導く純関数。位置を持たない全域一律の時間成分を返す。
// 位置ごとの補正は屋内判定などで別途足す。
func ClimateAt(cfg ClimateConfig, totalTurns consts.Turn) Climate
```

### 暖の経済

プレイヤーは暖 `Warmth` を持つ。屋外では気候の `Coldness` に比例して単調に減る。火のそばや屋内で回復する。ゼロを下回ると凍傷が始まる。

```go
// Warmth はプレイヤーの暖かさ。屋外で減り、火と屋内で回復する。単調でなく回復もある実行時状態。
type Warmth struct {
	// Current は現在の暖。0 を下回ると凍傷判定へ入る
	Current int
	// Max は上限
	Max int
}
```

暖の回復源は火。火は燃料を焚いて維持する。屋内は暖の減少が小さい上位互換の退避先で、燃料の消費が屋外の焚き火より少ない。屋外でも燃料があれば焚き火で暖をとれる。これで吹雪の退避を建物に依存させず、逃げ場なしの理不尽を避ける。

### 移動の駆動は枯渇 pull

前線という強制装置を外す代わりに、局所資源の枯渇を唯一の移動駆動輪にする。リージョンごとに燃料と食料が有限に埋蔵され、採ると減り、再生しない。滞在して漁り尽くすと暖と食料が続かなくなり、続きの資源がある東へ自分の意思で動く。

```go
// RegionStock はリージョンの資源埋蔵。採取で減り再生しない。枯渇が東進の誘因になる。
// 位置由来の決定論で初期量を導き、消費分だけを永続化する。
type RegionStock struct {
	// Fuel は残りの燃料量
	Fuel int
	// Food は残りの食料量
	Food int
}
```

左へ戻れないことと非再生が対になる。枯れた土地を farm できないので、前進しないと資源が尽きる。強制でない自然な圧になる。

### 左戻り不可を前線から切り離す

現状 `worldstream.Front` の極低温ゾーン西端 `ColdZoneWest` が破棄と進入不可ラインを兼ねている。前線を廃すので、この境界をストリーミングの破棄機構へ戻す。到達した最西端を境界として保持し、そこより西へは戻れず、破棄済みチャンクは復元しない。境界は前線のように時間で東進せず、プレイヤーの到達位置に従う。

```go
// DiscardBoundary は左戻り不可の境界。プレイヤーが到達した最西端の絶対 X。
// 前線と違い時間で進まず、後退を封じるためだけに存在する。
type DiscardBoundary struct {
	// WestAbsX はこの絶対 X 以西へは戻れず、以西のチャンクは破棄する
	WestAbsX consts.AbsTileX
}
```

### 吹雪の窓と退避

吹雪は `BlizzardWarnTurns` 前に予告する。窓のあいだ屋外の `Coldness` が跳ね上がり、暖の減少が加速する。プレイヤーは予告のうちに退避を決める。屋内へ入るか、燃料を確保して焚き火に籠もるか、東へ抜けるか。退避は安全と引き換えに時間と燃料を食う。窓が明けると平時へ戻り、雪解けの採集機会を置く余地がある。

### 失敗の連鎖と身体システム

暖がゼロを割ると凍傷が始まる。末端の部位から凍傷の hediff が付き、部位の capacity が下がる。即死でなく累積で、備えた者ほど有利になる。凍傷の部位別モデルは身体システムの設計に接続する。

### 危険度軸との合成

枯渇 pull は東へ引く。危険度軸は東ほど敵とアイテムが強く希少になる。結果として、生き延びるために資源を求めるほど、より危険な東へ引き込まれる。押されるのでなく、飢えと寒さが自らをリスクの中へ運ぶ。左戻り不可は、後退で危険度逓増を無効化させないための担保でもある。

## 採用しなかった方法

- **寒波前線を残す**。強制的な空間押し出しは agency を奪う。移動を枯渇 pull へ置換し、前線を廃す。
- **7 Days to Die 型の基地籠城**。ruins には建設も基地も無く、屋内で能動的にする遊びが無い。退避は既存建物と焚き火に限り、吹雪中の緊張は備蓄の残量と到達判断が担う。中で何をするかでなく、いつ動くかに緊張を乗せる。
- **吹雪の退避を建物必須にする**。建物が近くに無いと逃げ場なしの理不尽死になる。燃料があればどこでも焚き火で耐えられるを基本にし、建物は消費が少ない上位互換の退避先にする。
- **危険度軸に季節を畳み込む**。危険度は日数で単調増加、気候は吹雪で振動する。形が違うので別軸に保つ。
- **前線の破棄機構を流用したまま前線だけ止める**。破棄が時間で東進し続け、止まった前線と齟齬が出る。破棄は `DiscardBoundary` としてプレイヤー到達位置に従わせ、時間駆動から切り離す。

## コメント

開いた論点はほぼ数値で、実プレイでの調整に属する。

- 枯渇経済の数値。リージョンあたりの燃料と食料の埋蔵量、1リージョンで保つ日数と吹雪の回数、枯れてから次の補給へ届く距離。ここが弱いと移動 pull が成立せず、強いと窒息する。設計全体の荷重を支える一点。
- 吹雪の周期と予告リードタイム。予告が短いと理不尽、長いと緊張が薄れる。
- 暖の減少レートと火の回復量、屋内と屋外の焚き火の効率差。
- 危険度軸との配合。枯渇でどれだけ東へ引き、危険度でどれだけ東を危険にするか。
