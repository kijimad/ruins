# config を singleton エンティティへ移し状態の持ち方を揃える

## 背景

実行設定 config は `config.Load()` が環境変数から読み、`World.Config *config.Config`
というフィールドで保持している。一方でゲーム中の状態は singleton コンポーネントに載せ、
`query.GetSingleton[T]` で `world.Resources.SingletonEntity` から引く流儀に揃えている。
config だけが World の直下フィールドで、状態の持ち方が二本立てになっている。

config を singleton エンティティのコンポーネントに含めれば、ほかの状態と同じ引き方に統一でき、
「どこから状態を読むか」が1つの流儀に収まる。
