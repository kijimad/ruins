# キューブを展開している間は帯を止め、燃料をゆっくり戻す

## 背景

要件は設計ドキュメント 261125003808 で決めた。一巡は、錨を下ろして遠征を繰り返し、7日ごとの襲撃を乗り切って北へ発つ。その土台が錨である。

- キューブを展開することが、錨を下ろすことになる。錨の間は帯がずれず、帯の範囲がそのままエリアになる。エリアの中は東西南北どこへでも遠征できる
- 錨の間、帯の端は越えられない
- 錨を上げると、帯はまた北へ流れる。その場の世界は作り直さない
- 錨の間、キューブは燃料をゆっくり吸い上げる。詰みを防ぐためのもので、遠征で持ち帰る方がずっと多く得られる

今の地上では、プレイヤーが中央の行より北へ出ると、すぐに帯が北へずれ、南端の行が消える。拠点から北へ4チャンク進むと、拠点の行は消える。展開したキューブを置いたまま北へ行くと、キューブも消える。今はそれを避けるため、キューブが南端の行に入るとログで警告している。

今の作りで、錨に要るものはほぼそろっている。

| 要るもの | 今の作り |
|---|---|
| 錨の状態 | 展開中のキューブは `Deployed` を持ち、保存される |
| 帯がずれる所 | `overworld.Driver.MaybeShift` の1か所だけ |
| 端を越えられない | `activity.CanMoveTo` は地図の範囲外を通さない。帯がずれなければ北の端は越えられない |
| 設備が錨の間だけ働く | 設備は展開した野営の中にだけ置け、畳むと貨物に戻る |
| 燃料の入れ物 | キューブは燃料を `Charge` の `Pool` で持つ |

## 設計

### 錨は展開中のキューブから導く

新しいコンポーネントは足さない。錨の状態は、現ステージに `Deployed` を持つキューブがあるかから、読むたびに導く。展開の状態はすでに保存されるので、保存の仕組みも変えない。

```go
// internal/world/query/cube.go

// IsAnchored は現ステージに展開中のキューブがあるかを返す。展開中のキューブが錨になり、地上の帯をずらさない
func IsAnchored(world w.World) bool
```

キューブは2台目も作れるので、どれか1台が展開していれば錨とする。

### 錨の間は帯をずらさない

`Driver.MaybeShift` の冒頭で、錨の間は何もせず戻る。

```go
func (dr *Driver) MaybeShift(world w.World) (bool, error) {
	if query.GetTurnState(world).Phase != gc.TurnPhasePlayer {
		return false, nil
	}
	if query.IsAnchored(world) {
		return false, nil
	}
	// 以下は今のまま
}
```

- 錨の間、プレイヤーは北の端まで歩ける。北の端から先は地図の範囲外なので、`CanMoveTo` が通さない。東西と南の端も今のまま越えられない
- 錨を上げると、次の `MaybeShift` で、プレイヤーが中央の行に収まるまで帯をまとめてずらす。今のループがそのまま収束させる
- 錨の上げ下ろしは、キューブに隣接して開くメニューでだけできる。錨の無い間、プレイヤーは中央の行より北へ出るとすぐ帯がずれるので、錨を下ろす位置は中央の行か、それより南になる。エリアの北には少なくとも4行が残る

### 錨の間は燃料をゆっくり戻す

ターンの終わりに、展開中のキューブの燃料を少しずつ容量まで戻す。

```go
// internal/systems/anchor_fuel.go

// AnchorFuelSystem は展開中のキューブの燃料を、anchorFuelTurns ターンごとに1ずつ容量まで戻す。
// 錨の間に燃料が尽きて詰むのを防ぐためのもので、遠征で持ち帰る燃料よりずっと少ない
type AnchorFuelSystem struct{}

// anchorFuelTurns は燃料を1戻す間隔のターン数
const anchorFuelTurns = 10
```

- 1日は1500ターンなので、1日に150戻る。空のキューブが1歩ついて来るのに5かかるので、1日で30歩ぶんになる。満タンで約600歩なので、1日で5%ほどである
- 間隔は `GameTime.TotalTurns` で数え、カウンタは持たない。経過ターンが `anchorFuelTurns` で割り切れるターンにだけ戻す
- `runTurnEndSystems` の並びと `InitializeSystems` の登録の両方に足す
- 退避中のステージのキューブは戻さない。`query.ActiveFilter` で現ステージだけを見る

### 錨の名前は画面で語らない

ログやメニューに錨という言葉は出さない。展開のメニューの文言も変えない。帯の端の吹雪の見た目は、この文書では作らない。

## 採用しなかった方法

| 案 | 採らなかった理由 |
|---|---|
| 錨の状態を新しいコンポーネントで持つ | 展開の状態から導けるので、二重に持つと食い違う |
| 錨の間だけ帯を広げる | 帯の仕組みを変える大きな変更になる。広さは遊びながら調整する |
| 錨の間、北の端に吹雪の壁を見せる | 見た目は通しで遊べる形がそろってから足す。越えられないことは今の地図の範囲で守れる |
| 北の端で足止めされたときにログを出す | 東西の端も今は何も言わない。端の見せ方は吹雪の見た目とまとめて考える |
| 燃料を毎ターン小数で戻す | 燃料は整数で持つ。間隔のターン数で量を決める方が単純 |

## コメント

- 錨を上げた直後、プレイヤーが北の端の近くにいると、1回の `MaybeShift` で何行もずれる。錨を上げるのはキューブの所なので、普通は中央の行の近くで、ずれるのは数行で済む
- 南へ戻ってから錨を下ろすと、エリアは北に広く南に狭くなる。消えた南は作り直せないので、そのまま受け入れる
- 燃料の戻る量は、通しで遊んで調整する
- デバッグ用の区域へのジャンプ `JumpToDistrict` は、錨の間でも帯をずらす。展開したキューブは南へ取り残されて消えうる。デバッグ用なので止めない

## 進捗

- [ ] `IsAnchored` を足し、展開中のキューブがあるときだけ真になることをテストで固める
- [ ] `MaybeShift` で錨の間は帯をずらさない。北の端まで歩いてもずれず、錨を上げると中央の行までずれることをテストで固める
- [ ] `AnchorFuelSystem` を足し、`runTurnEndSystems` と `InitializeSystems` の両方に登録する。間隔ごとに1戻り、容量を超えず、畳んだキューブは戻らないことをテストで固める
- [ ] 遊んで、錨を下ろしたエリアを歩き回れることと、錨を上げると北へ流れることを確かめる
