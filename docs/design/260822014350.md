# 逓増: 危険と希少性の軸を深さから距離と日数へ移す

## 背景

マクロループ設計 `260821223229` の④逓増を詳細化する。現状の難易度軸は深さ `Depth` で、`raw.go` の spawn テーブルが `MinDepth`/`MaxDepth` でエントリをゲートし、`consts.GameClearDepth` がクリア判定に使われている。これは旧ダンジョン潜降型の軸であり、一方向逃避では縦深より横広の1世界に合わせて、**前進距離と経過日数**を軸にする。

将来方針としても深さは廃していく。オーバーワールドを主軸に、縦の depth 層は過渡的なものとして扱う。

## 要件

**Hard**

- 危険と希少性は前進距離と経過日数の関数で決まる。`Depth` を軸に使わない。
- 危険度は決定論の純関数で出す。保存状態を増やさない。
- spawn テーブルのゲートを危険度基準へ移す。敵の強さ・数・アイテムの希少度が距離と日数で変わる。
- `consts.GameClearDepth` を退役させる。クリアは終端 doc `260822014348` の生還条件が引き継ぐ。

**Soft**

- 遠くへ行くほど良い物が出る。危険と報酬が同じ軸で伸び、深追いの賭けが成立する。
- 日数の寄与で、同じ場所に籠もっても世界がゆっくり厳しくなる。前線の接近と重なって滞在を罰する。
- 危険は施設の種別と雰囲気で伝わる。軍事施設のような場所や荒れた景観が危険を示し、数値では読ませない。

**Anti**

- 深さと距離の二軸を併用しない。旧軸の綱引きを温存しない。
- プレイヤーレベルへの動的スケーリングをしない。世界の危険は場所と時間で決まり、育成の意味を守る。
- 危険度を数値で表示しない。危険は施設種別と雰囲気で diegetic に伝える。

## 設計

### 危険度の純関数

```go
// DangerLevel は前進距離と経過日数から危険度を返す純関数。
// 距離が主、日数が従。単調非減少で、同じ入力は常に同じ危険度を返す
func DangerLevel(dist consts.AbsTileX, days int) int

// DangerLevelAt は world から現在地と時刻を引いて DangerLevel を呼ぶラッパー
func DangerLevelAt(world w.World, absX consts.AbsTileX) int
```

距離を主にするのは、前進というプレイヤーの主体的な選択をリスクに反映するため。日数を従で足すのは、籠もりでも世界が厳しくなり、駆動 doc `260822014347` の前線接近と合わせて滞在を罰するため。配合比とカーブは実測で決める。

### spawn テーブルの移行

`raw.go` のゲートを深さから危険度へ移す。スキーマは tsp が源泉なので、`ruins-tsp` の手順で変更する。

```
変更前: minDepth / maxDepth  でエントリをゲート
変更後: minDanger / maxDanger でエントリをゲート
```

移行は2段で行う。まず機械置換として、既存の depth 値を同じ数の danger 値へ写して挙動を保つ。次に調整として、実プレイで距離あたりの危険の伸びを測り値を振り直す。1段目で `make check` が通る状態を保ち、2段目を独立に進められる。

### 退役

- `consts.GameClearDepth` を削除する。参照点はクリア判定で、終端 doc の生還条件へ置き換わる。
- `Depth` フィールド自体は当面残る。ダンジョン内の階層表現としての深さは残り、**難易度軸としての参照だけを外す**。全廃は縦深の扱いを決める将来 doc に委ねる。

### 危険は施設種別と雰囲気で伝える

危険度は内部値に留め、数値では見せない。プレイヤーは**どんな場所か**で危険を読む。距離と日数の危険度は、その場に現れる施設の種別と敵の湧きを重み付けする入力にする。遠く・後半ほど、軍事施設のような高危険の場所が出やすくなる。軍事施設は明らかに危険、廃屋は穏やか、と施設種別そのものが警告になる。加えて荒れた景観・照明・音といった雰囲気で危険の気配を滲ませる。危険を数値でなく世界の観察から読ませることで、深追いの賭けが没入を壊さずに成立する。

## 採用しなかった方法

- **深さと距離の二軸併用**。ダンジョン内は深さ、地上は距離でゲートする。却下。旧軸が残ると spawn 定義が二重になり、新旧の綱引きを温存する。ダンジョン内の危険も入口の位置の危険度を引き継げば一軸で表せる。
- **日数だけを軸にする**。却下。距離が効かないと前進のリスクとリターンが消え、主体的な選択が危険に反映されない。
- **距離だけを軸にする**。却下。籠もりが安全になり、滞在を罰する前線との噛み合わせが弱まる。
- **プレイヤーレベルへの動的スケーリング**。却下。世界の危険が育成に追随すると、強くなる意味と場所の個性が消える。
- **危険度を数値で表示する**。観察やステータスに危険帯の数字を出す。却下。ゲームっぽく没入を削ぐ。危険は軍事施設のような施設種別と、荒れた景観や雰囲気で伝えるほうが、探索の読みが世界の観察になる。

## コメント

距離と日数の配合比・カーブ・危険帯の刻みは実測で決める。移行1段目の機械置換では体感を変えないことを優先し、危険の伸びの調整は2段目で行う。
