# 地上で新しいエリアに入ったらスプラッシュを出し、右下に現在地を出す

## 背景

地上には区域・集落・目印・遺跡の入口があるが、今どこにいるかが画面に出ない。地図を開くまで、町に入ったことも、立っている建物が診療所か商店かも分からない。

場面の節目を大書きで知らせるスプラッシュ `lifecycle.SpawnSplashText` は、日付の変わり目とダンジョンに入ったときにだけ使っている。参考 codebase: `internal/world/lifecycle/spawn.go:357`。

チャンクの場所は位置と seed の純関数で引ける。`chunkTypeAt` がチャンクを5種類に分け、市街地なら `districtAt` で区域を、`urbanFacilityAt` でそのチャンクの施設を引ける。参考 codebase: `internal/overworld/schematic.go:94`。

## 要件

1. 地上でエリアが変わったら、エリアの名前をスプラッシュで出す。エリアは区域、集落、目印、遺跡の入口の単位にする。
2. 荒れ地に出たときはスプラッシュを出さない。荒れ地は地上の大半を占める残りの場所で、町を出るたびに出ると煩わしい。
3. 同じ種類でも別の区域に入れば出す。隣の町に移ったときも知らせる。
4. 右下に「エリア名 / 建物名」を出す。建物名は市街地のチャンクにいれば出す。
5. ゲームの開始やロードの直後は出さない。エリアに入ったのではなく、そこから始まるため。

## 設計

### チャンクのエリアを引く

```go
// Area は地上のチャンクの場所
type Area struct {
	Key      string // エリアの同一性。同じなら同じエリア。荒れ地は空
	Name     string // エリアの表示名の msgid
	Building string // 市街地の建物の表示名の msgid。市街地でなければ空
}

// AreaAt はチャンク c のエリアを返す
func AreaAt(raws rawschema.Raws, runSeed uint64, c consts.Coord[consts.Chunk], cols, spawnRow consts.Chunk) Area
```

| チャンクの種類 | Key | Name | Building |
|---|---|---|---|
| 市街地 | 区域の種類と原点 | 区域の行の `name` | 施設の地図記号の名前 |
| 集落・目印・遺跡の入口 | 種類とチャンクの座標 | 地図記号の名前 | 空 |
| 荒れ地 | 空 | 地図記号の名前 | 空 |

- 区域の Key に原点を含めるので、同じ種類の別の区域に移っても Key が変わる。
- 施設・集落・目印・荒れ地の表示名は、地図の凡例と同じ地図記号の行の名前を使う。
- 区域には名前の欄が無いので、`#District` に `name` を足す。

### エリアの変化でスプラッシュを出す

```go
// AreaEntrySystem はプレイヤーのいるエリアが変わったら、エリアの名前をスプラッシュで出す
type AreaEntrySystem struct {
	last     string // 直前のエリアの Key
	observed bool   // 一度でもエリアを見たか
}
```

- ターンの終わりに回す。プレイヤーが動いた後に現在地を見る。
- 直前のエリアは system が持ち、セーブしない。最初に見たエリアは記憶するだけで出さないので、開始とロードの直後は出ない。
- 地上でなければ何もしない。

### 右下に現在地を出す

天候と気温の行の上に、`エリア名 / 建物名` の1行を足す。建物が無ければエリア名だけを出す。地上でなければ出さない。

## 採用しなかった方法

- **建物が変わったときにもスプラッシュを出す**: 市街地はチャンクごとに建物が変わるので、数歩ごとに出てうるさい。建物名は右下だけに出す。
- **荒れ地に出たときにもスプラッシュを出す**: 町を出るたびに出て煩わしい。
- **直前のエリアをコンポーネントに保存する**: 直前のエリアは現在地から導けないが、ロード直後に出さないことにすれば保存は要らない。
- **区域の名前を地図記号の行から引く**: 区域は地図記号を持たず、地図は区域の中の施設を描く。区域の行に名前を持たせるのが素直。
