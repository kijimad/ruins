# 通信販売: オークション形式の販売機構

## 背景

通信販売はこのゲームのコアである。設計 doc 260813235334 で、拾った物に自分の生存に加えて市場という第二の需要を足し、使う・送る・捨てるの三択をコアに据えた。本 doc はその販売機構を、オークション形式で手厚く具体化する。

販売を手厚くするのは、ここに目的とやりがいを生むためである。何を拾い、何を鑑定し、いつ売り、どう発送するかの連鎖判断が、プレイヤーが探索へ挑むインセンティブを強化する。単に金を得る作業でなく、読みと駆け引きのある行為にする。

肝は、価値がそのまま利益にならないことである。発送料と手数料、個体差、市況、販売スキル、鑑定による情報格差、そして売るまで価格が分からない不確実性を噛ませる。これにより、ゴミ拾いが儲かる単純換金を排し、判断のあるゲームにする。

## 要件

**Hard**

- 全アイテムを出品できる。ただしクラフト素材やありふれた物は利益が出にくい
- 価値は利益に直結しない。発送料は重量に依存し、手数料は落札額に依存する。重い安物やゴミは赤字になりうる
- 売値は売るまで確定しない。過去の売却履歴から推定するしかない
- 同じ物でも個体差と市況と販売スキルで価格が変わる
- 操作はタイル上で完結する。出品ラベルを物体に貼る、発送ラベルを落札された出品物に直接貼る、その品を発送ゾーンへ置く。別画面のショップに閉じない
- 一方向の逃避と両立する。手取りは前へ進む糧であり、貯め込んで安住する装置にしない。260813235334 の不変条件を継承する

**Soft**

- 鑑定で隠れた個体パラメータが開ける、情報を開ける楽しみ
- 高額な物を売るほど販売スキルが伸びる成長
- 出品ターン数で換金速度と値段のトレードオフを選べる
- 出品物にラベルを貼り、発送ゾーンへ運ぶ物理操作の手触り
- 整理は工夫の余地ある技能である。良い体系は速い取り出しで報われる

**Anti**

- 固定価格の即時換金にしない。判断が消えて作業になる
- 価値がそのまま利益になる直接変換にしない
- 別画面のショップ UI に閉じない
- 鑑定なしで全パラメータを最初から見せない
- クラフト素材やありふれた物で簡単に儲けさせない
- 在り処ハイライトや全体検索で物を突き止めさせない。整理の動機を殺す
- 自動仕分けや自動ピッキングをしない。整理と取り出しの動詞を奪う

## 設計

本節は機構の概念を企画として述べる。データ構造と実装の詳細は、コア検証を経てから設計 doc で定める。

### 個体差と鑑定

同じ raw の物でも個体ごとにパラメータが異なり、価格を左右する。現実同様、物によって基準価格そのものも異なる。

- 個体差は保存状態・プレミア度・年式で表れる。同じ物でも状態や希少性、古さで価格が動く。未鑑定のうちは伏せられる

- 細かいパラメータは鑑定によって見えるようになる。鑑定は行動であり、未鑑定のまま売るとリスクを負う

### 出品とオークション

- 出品タグは発券機で発行し、持ち物として持ち歩く。タグは同一の消耗品で個体差を持たない
- タグを品に貼ると出品される。貼った瞬間に一意識別子を採番し、以後その出品を識別子で指す。識別子は出品タグでなく貼られた品の側に宿す
- 出品状態は出品中・落札済みと移る。出品 UI で出品中の一覧と各出品の状況を確認できる
- ターン経過によって入札や落札が進む。出品ターン数は指定でき、換金速度を取るか値段を取るかを決められる

### 落札と発送

- 落札はパラメータ次第の確率で決まる。出品期間が満了しても必ず売れるわけではなく、高価な品ほど買い手が付きにくい
- 落札されなかった品は在庫として残る。再出品でき、そのつど識別子は採番し直しになる。同じ物でも出品のたびに識別子が変わる
- 落札した品は発送ゾーンへ運んで発送する。発送ゾーンは連れ歩く家に設けた一区画で家と共に動き、固定の外部拠点は作らない
- 発送ゾーンの操作の具体は未決とする。候補は「収納として品を入れる」「専用の発送操作で送る」「ゾーンのタイルに直接置いて送る」の三つ。品が収納に隠れず床に見えること、置く手触りがあることを条件に、コア検証の手応えを見て選ぶ
- 誤発送と期限のペナルティは骨格として違約金と評判低下の二段とする。評判が下がると以後の入札が渋り高値が付きにくくなる。取引を止める強制退場のような系は取らない。金額と評判の減衰量はコア検証後に確定する

### 価格モデル

売却額はおおよそ次の要素で決まるが、売るまで確定しない。

```
落札額 ≈ 基準価格(raw) × f(Condition, Premium, Vintage) × 市況(Boom, Economy) × g(販売スキル)
手取り = 落札額 − 発送料(重量に比例) − 手数料(落札額に比例)
```

- 発送料は重量に応じる。だからゴミや重い安物を売っても手取りが出ない。価値が利益に直接つながるわけではない
- 手数料は販売あたりに取られる。薄利は手数料で消える
- クラフト素材やありふれた物は基準価格が低く、発送料と手数料で利益がほぼ出ない。これで簡単な換金を構造的に防ぐ

### 市況

- ブームと景気という市況パラメータによって価格が変わる。今が売り時かの読みが生まれる。ブームはカテゴリ別に効き、カテゴリは raw のアイテムカテゴリを単一源泉として再利用する

### 販売スキルと成長

- プレイヤーキャラの販売スキル値によって価格が変わる。係数として落札額に効く
- 高額なものを販売すると販売スキルが成長する。育つほど同じ物でも高く売れ、探索と販売の反復に上りの螺旋が生まれる

### 不確実性と履歴

- いくらで売れるかは売るまでわからない。売った履歴で判定するしかない
- 履歴を積むほど期待値の見当がつき、経験が読みに変わる
- 見えるものと見えないものの境界を決める。未鑑定品は個体パラメータが伏せられ、鑑定で開く。履歴は一覧で参照できる。推定は確定値でなくレンジとして示し、売るまで正解は分からない

### 整理とピッキング

内部空間は拾った物を収める倉庫であり、注文が来たら落札された品を探し出してラベルを貼り、発送ゾーンへ運ぶ。この探し出しを、整理という技能の勝負にする。

- 収納ゾーンはプレイヤーが区切り、自分で目印のラベルを付ける。分類はゲームが強制しない

- 一意識別子は個体を指すが、並べ替えの鍵にはしない。売れ残りと再出品で識別子が入れ替わるため、識別子順に倉庫へ並べる整理は成立しない。整理は種別・価値・重量など物の安定した属性で工夫させ、識別子は注文の同定にだけ使う

- **整理を工夫の面白さにする**。限られた内部空間、予測できない注文、背後に迫る寒気の締切という制約下で、増える collection をどう並べれば速く捌けるかを自分で設計する。種別順・価値順・頻度順・重量順など最適解は1つでなく、組み方の違いが工夫と個性になる
- **補助はプレイヤーの構造を映すだけ**。自分で書いたゾーンや収納のラベル一覧を辿れる。収納を覗けば中身の種類と数が見える。同種は自動でスタックし、隣接すればメニューを潜らず掴める。いずれも整理した人にしか役立たず、雑に放り込めば役に立たない
- **在り処は代行しない**。ゲームは物の位置をハイライトも全体検索もしない。無整理でも突き止められると整理の動機が消えるためである。探し出しはプレイヤーの体系と記憶が担う
- **帰結で報いる**。良い体系は注文の瞬間に自分のラベルを辿って最短で品へ到達する。雑なら自分の山を締切下で掘る。ゲームは整理を強制も代行もせず、体系の良し悪しを取り出し速度で突きつける

### 一方向の逃避との両立

- 260813235334 の不変条件を守る。手取りは前へ進む糧で、貯め込んで安住する装置にしない
- 出品と発送ゾーンは連れ歩く家に付随し、戻る固定市場を作らない

## 採用しなかった方法

- **固定価格の即時換金**。判断が消えて作業になる。オークションと不確実性で悩ましさを作る
- **市場へ運んで対面で売る**。戻る循環を作り、一方向の逃避と衝突する。260813235334 で却下済み
- **別画面のショップ UI に閉じる**。タイル上の貼る・運ぶ・発送ゾーンの手触りを捨てる。単一解像度の世界を壊す
- **鑑定なしで全パラメータを最初から開示**。情報を開ける楽しみと未鑑定の博打が消える
- **価値をそのまま利益にする直接変換**。ゴミ拾いが儲かり探索の判断が薄れる。発送料と手数料で価値と利益を切り離す
- **クラフト素材も普通に儲かる設計**。ありふれた物で簡単に稼げると経済が壊れる。低い基準価格と料金で利益を出させない
- **在り処ハイライトや全体検索で物を突き止める**。無整理でも品を見つけられ、整理する動機が消える。探し出しはプレイヤーの体系と記憶に委ねる
- **自動仕分けや自動ピッキング**。整理と取り出しという満たす動詞そのものを奪う。補助はプレイヤーが作った構造を映すだけに留める
- **発送タグを出品タグと別に発行させる**。発券と貼付の手順が二重になり無用に煩雑。発送は落札品を発送ゾーンへ運ぶだけにする
- **一意識別子を出品タグ側に持たせる**。複数のタグと複数の品があると「どのタグをどの品へ」という無意味な組合せが生まれる。識別子は貼った品に宿し、タグは同一の消耗品にする

## コメント

- 通信販売はコアなので手厚く設計する。ここに目的とやりがいが宿り、探索インセンティブが強化される
- 最大の勘所は、価格の不確実性と、価値と利益の分離である。単純換金でなく、何を拾い、鑑定するか、いつ売るか、どう発送するかの連鎖判断にする
- 本 doc は 260813235334 の第二需要の具体化であり、一方向の逃避と貯め込ませない不変条件を継承する
- コアの面白さは実装前に最小形で検証する方針を継ぐ。オークションの悩ましさと、価値≠利益の緊張が毎回成立するかを先に確かめる
- 手応えはグレイボックスのデモで実測中である。デモはデバッグメニューから起動し、床への配置・発券機・出品タグの貼付・確率落札・在庫残り・発送を最小形で触れる。進行はターンの代わりに移動歩数を単位にしている。ターン進行がデバッグ場面で凍結する事情を避け、歩けば必ず進む形で手応えだけを見るための検証用の割り切りで、本実装の進行単位を定めるものではない
