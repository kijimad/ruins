# 地面の雪を気温と同じ式から導き、寒さを画面に出す

## 背景

北へ進むほど寒くなり、冬の底は -30℃ になるのに、オーバーワールドの地面は砂漠に見える。地面の基調が橙の `dirt` で、ムラも砂の橙・赤・桃で出しているためである。参考 codebase: `internal/overworld/scatter.go:82`。

地面の見た目と気温は別々に決まっていて、つながりが無い。寒い場所でも暖かい場所でも同じ絵になり、寒さが画面から伝わらない。

素材は足りている。DawnLike の `Floor.png` にある autotile の28組は、すべてタイルとして切り出し済みである。雪原に近い淡い白の `smooth_white`・`smooth_cream`、霜や氷に近い `smooth_bluegray`・`smooth_teal` がある。

気温は次の項の和で、判定に使う1つの式にまとまっている。参考 codebase: `internal/world/query/temperature.go:58`。

| 項 | 変わる単位 |
|---|---|
| ステージの基本気温 | ステージ |
| 季節 | 日。32日で1周 |
| 緯度 | 北へ1チャンクごとに -1℃、最大 -40℃ |
| 時間帯 | 1日に数回 |
| 天候 | 数時間 |
| 屋内外・タイルの補正 | 場所 |
| 熱源 | 焚き火の近く |

## 要件

1. 地面の雪は、判定に使う気温と同じ式から導く。寒い場所は白く、白い場所は寒い、が仕組みで保証される。
2. 雪は積もって残る。1日の中で時間帯や天候によって地面がちらつかない。
3. 雪は屋根の無い地面に積もる。屋内の床・壁・水には積もらない。積もるかどうかは地面の種類を選ばず、土・砂・草・道・コンクリートに積もる。積もる量はタイルの行の `snowMeltPercent` の割合だけ減らす。道は 60 で、真冬でも石畳が透けて見える。
4. 地図は位置から導く方針を保ち、地面のエンティティを書き換えず、保存も要らない。
5. 雪が積もる気温の幅は1か所に置く。
6. 気温が下がるにつれ、雪がだんだん厚く広く積もる。ある地点やある日を境に急に白くならない。

## 設計

### 気温の式を、その日の平均とその瞬間の揺れに分ける

```go
// ClimateTemperatureAt は屋外のその日の平均気温。ステージの基本気温+季節-緯度。
// 時間帯・天候・屋内外・熱源を含まないので、1日の中では変わらない。地面の雪はこの値から導く
func ClimateTemperatureAt(world w.World, y consts.Tile) int

// AmbientTemperatureAt はその瞬間の気温。ClimateTemperatureAt に時間帯と天候を足した世界温度を
// 屋内外で緩め、タイルの補正と熱源を足す。判定は今までどおりこちらを使う
func AmbientTemperatureAt(world w.World, x, y consts.Tile) (int, error)
```

- 季節と緯度は `AmbientTemperatureAt` の中で直接足していたのを、`ClimateTemperatureAt` を通して足す形に改める。判定の値は変わらない。
- 時間帯と天候を外すのは、夜だけ積もって朝に消える、といった1日の中のちらつきを避けるためである。

### 雪の量

1つの閾値で一斉に切り替えると、ある地点やある日を境に地面が急に白くなる。マスごとに 0 から 1 の量で積もらせる。

```go
// 雪がまだらに積もる気温の幅
const (
	snowStartTemperature = 5  // その日の平均気温がこれ以下で積もり始める
	snowFullTemperature  = -30 // これ以下で屋根の無い地面の全てを覆う
)

// SnowFraction はその日の平均気温から、雪が積もる地面のマスの割合を 0 から 1 で返す
func SnowFraction(temp int) float64

// SnowRankAt はマスの順位を 0 以上 1 未満で返す。割合がこれを上回れば積もり始める
func SnowRankAt(world w.World, x, y consts.Tile) float64

// SnowAmount は割合と順位の差から積もる量を返す。縁ほど薄く、割合が1なら全てのマスが1になる
func SnowAmount(fraction, rank float64) float64
```

- 順位は、6マスほどの大きさでなめらかに変わる値を主にし、マスごとの揺らぎを2割混ぜる。雪は塊で積もり始め、寒くなるほど同じマスに雪が残ったまま塊が広がる。
- 量は、割合と順位の差を縁の幅で割って 0 から 1 に収める。塊の内側ほど濃く、縁ほど薄いので、境目がぼける。割合が1のとき全てのマスが1になるよう、割合を縁の幅ぶん引き伸ばす。
- 順位は絶対座標から決めるので、帯がずれても同じ場所は同じ値になる。座標を撹拌する `consts.Mix64` は、チャンクの seed の `ChunkSeed2D` と共有する。

### 雪が積もる地面を raw で示す

```cue
#Tile: {
	// ...
	// 雪が積もる地面か。屋根の無い場所で、その日の平均気温に応じた量の雪を重ねて描く
	snowable?: bool
}
```

```go
// Snowable は雪が積もる地面に付くマーカー
type Snowable struct{}
```

- 土・砂・草・道の床・コンクリート・石畳に `snowable = true` を付ける。屋内専用の床・壁・水・虚空には付けない。
- 屋根のある地面には積もらない。囲われの行の `covered` で決める。屋根の無い地面は世界温度をそのまま受けるので、その日の平均気温は判定の気温と一致する。
- 屋根の有無は扉の開閉で変えない。扉を開けて外気に繋がった部屋は、屋外でなく屋根のある半屋外 `partial` にする。屋外にすると、開いた部屋の床に雪が積もる。
- 水かどうかを列挙の値と比べて決めることは lint で禁じているので、積もるかどうかを行の欄で示す。

### 地面の上に雪の層を重ねる

`Render3DSystem.collectTiles` が地面を描いた直後に、`snowable` で屋根の無い地面なら、同じ位置へ雪の層を重ねる。参考 codebase: `internal/systems/render3d.go:316`。

- 雪の層は、積もる量を透明度にして描く。薄く積もったマスは下の地面の模様が透け、厚いほど白くなる。
- 雪の層は地面より `depth` を1つ上げ、同じ位置の地面より後に描く。
- 地面のエンティティは書き換えない。季節が進めば、次に描いた時点で雪が変わる。
- 雪の割合は1回の描画の中で行ごとに1回だけ求める。

### 雪の層の絵

土の絵 `dirt_15` の色を置き換えて、雪の層の絵 `snow` を1枚作る。

| 土の色 | 役割 | 雪の色 |
|---|---|---|
| 橙 `#D37D2C` | 地 | 白 `#EEF3F7` |
| 灰 `#757161` | 散らばった石 | 薄い青 `#C8D5E2` |

- 土と同じ模様なので、ざらついた雪原の質感が出る。
- 境目は量の濃淡でぼかすので、縁の形の絵は要らない。

## 採用しなかった方法

- **雪のタイルに差し替える**: 試したが、雪を描けるのが雪の絵の組を持つ地面に限られ、草や道は夏のままだった。雪か土かの2択なので、薄く積もった様子も描けない。地面の上に重ねれば、地面の種類を選ばず量の濃淡で描ける。
- **1つの閾値で一斉に切り替える**: 試すと、ある地点やある日を境に地面が急に白くなり、雪らしくなかった。緯度はチャンク単位なので、境目もチャンクの行で横一直線になる。
- **どのマスが積もるかをマスごとの乱数だけで決める**: 試すと、白と土が細かく入り混じって碁盤目に見えた。なめらかに変わる値を主にして塊にする。
- **地面を一面の雪の組に替える**: 変更は小さいが、気温とつながらない。北へ進む変化も季節の移ろいも見えない。
- **時間帯と天候も含めた瞬間の気温で雪を決める**: 夜だけ積もって朝に消える、と1日の中で地面がちらつく。雪は積もって残るものなので不自然。
- **熱源で雪を溶かす**: 焚き火の周りだけ土が見える演出は面白いが、まず基本の形を入れてから考える。
- **季節が変わったとき地面のエンティティを書き換える**: 地図を位置から導く方針を崩し、書き換えの時機と保存が要る。描く瞬間に差し替えれば状態を持たずに済む。
- **無地の `smooth_white` を雪の絵にする**: 試すと地面の模様が消えて単調だった。土の色を置き換えて質感を残す。
- **雪の模様の絵を新しく描く**: 絵の作業が要る。土の色の置き換えで足りた。
- **積もる地面を描く処理に直接書く**: 地面の種類が増えるたびに描く処理を直すことになる。raw の `snowable` で示せばデータで足せる。

## コメント

- 緯度はチャンク単位なので、雪の境目はチャンクの行で横一直線になる。季節が進むと境目が南北に動く。
- マクロ地図の色は別の設計で雪に合わせる。チャンクの行ごとに雪の割合を求め、セルの色を白へ寄せる。北の寒さと季節の雪の境目を地図で先に読めるようにする。
- 調べる画面には雪を出さない。雪は3D描画で見えている。
- 雪の閾値と季節・緯度の値は仮。実プレイで振る。
