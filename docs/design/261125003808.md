# 錨を下ろして遠征を繰り返し、乗り切って北へ発つ

## 背景

今のゲームには、ひとつの場所に留まって暮らす理由が無い。キューブを畳んで運ぶのは手番も燃料も使わず、どこで展開しても得るものは同じである。土地にも留まる理由が無い。拠点の周り 3×3 チャンクの食べ物と燃料で暮らせる日数を5つの seed で測ると、中央値で0日だった。敵は食べ物を落とさず、置物は壊しても燃料にならない。

そのため、拠点に愛着が生まれず、発つときに失うものも無い。ここでは、1つの土地で数日暮らし、乗り切って発つ一巡を、遊びの芯として組み立てるための要件を決める。

## 要件

### 体験の狙い

遊び終えた後も覚えている情景を2つ決め、それを実現するのに要る仕組みを逆算する。

| 情景 | 見えているもの | 思ってほしい一言 |
|---|---|---|
| 吹雪の夜 | 遠征から戻った夜。外は吹雪と獣の気配。整えた建物の中は暖かく、運んできた設備、蓄えた食べ物、持ち帰った物がある | ここは、自分で作った居場所だ |
| 発つ朝 | 錨を上げた朝、暮らしの道具をキューブに積んで雪原へ出る。振り返ると、世話になった建物は、襲撃の後の壊れた壁と、血の跡と瓦礫にまみれている | 乗り切った。世話になった。次へ行こう |

拠点への愛着は、手間をかけたこと、ここで乗り切ったこと、外から帰ってくる場所であることの3つから生まれる。思い出は、場所の個性と数日の暮らしから自然に生まれればよく、記録する仕組みは要らない。

### 一巡

1つのエリアでの一巡を、遊びの芯にする。

1. 北へ旅をして、建物と近くの危険な施設を見て回り、拠点にする場所を決める
2. 建物に巣くう者を追い出し、キューブを展開して錨を下ろす。帯が止まり、周りがエリアになる
3. 拠点を整え、近くの危険な施設へ遠征を繰り返す。持ち帰って蓄え、直し、作る
4. 暦どおりに来る襲撃を、整えた拠点で乗り切る。襲撃はエリアの山場になる
5. 乗り切った朝、錨を上げて北へ発つ。鍵を揃えきれなかった分は、次のエリアで補う

拠点は遠征を支える場所である。蓄える、暖まる、治る、作り直す。そのどれも外では得られない。襲撃の夜は遠征の締め切りにもなり、どこまで深く潜り、いつ引き返すかが毎回の判断になる。発つ理由は、尽きたから仕方なく移るよりも、次の土地の方が良い物がある、という欲に置く。1つのエリアで越える襲撃は1回と仮に置き、遊んで確かめる。

### 挑戦の弧

- 挑戦は墜落から始まり、北の果てで脱出の手段を直して惑星を出ると終わる。エリアは10くらいを通る
- 最高潮はクリアではなく暮らしが整っていくことだが、脱出は挑戦の終わりと、北へ進み続ける理由になる
- エリアの一巡を10回繰り返しても単調にならないよう、エリアごとに違いを持たせる

### 錨と地図

- キューブを展開することが、錨を下ろすことになる。錨の間は帯がずれず、帯の範囲がそのままエリアになる。エリアの中は東西南北どこへでも遠征できる
- 錨の間、帯の端は越えられない吹雪の壁になる。置いてきたキューブが帯のずれで消えることは起きない
- 錨を上げると、帯はまた北へ流れる。旅は北への一方通行で、南の消えた行は戻らない。錨を上げても、その場の世界は作り直さない
- 帯の中の行は、漁った跡、吸い上げた跡、直した所を持ったまま残る。錨を下ろし直しても、新しい物は帯の外の北にしか無い
- 設備が働くのは、錨の間だけにする。拠点がくれるもの全部が、錨を下ろす動機になる
- 錨の間、キューブは土地から燃料をゆっくり吸い上げる。詰みを防ぐためのもので、遠征で持ち帰る方がずっと多く得られる釣り合いにする
- 仕組みの名前は画面で語らない。帯の端の吹雪と、展開すると世界が落ち着く感覚で伝える

### 情景から逆算した、要る仕組み

| 情景 | 要る経験 | 要る仕組み | 今 |
|---|---|---|---|
| 吹雪の夜 | 外が過酷である | 寒さ、吹雪、獣。夜は視界の外に敵が湧き、漁り尽くした土地でも安全にならない | 寒さと天候はある。湧き直す仕組みは無い |
| 吹雪の夜 | 帰ってくる場所である | 近くの危険な施設への遠征。重さ、傷、寒さで限界があり、拠点で回復する | 施設、敵、重さ、健康はある。拠点を据えて遠征する仕組みは無い |
| 吹雪の夜 | 建物の中は暖かい | 運んできた暖房の設備。直した壁と塞いだ窓で暖が逃げない | 無い |
| 吹雪の夜 | 自分で整えた | 壊れた所を直し、置き物で塞ぎ、設備を置く | 置く仕組みはあるが、働く設備が少ない。直す、地上に置き物を置く仕組みは無い |
| 吹雪の夜 | 蓄えがある | 遠征で持ち帰る。狩りと罠で食べ物を得る。加工して日持ちさせる | 狩りと罠は無い |
| 吹雪の夜 | 最初は何も無かった | 着いた直後は足りず、日を追って整う | 無い |
| 発つ朝 | 乗り切った | 暦どおりに来る襲撃が、錨のキューブを狙う。機銃と塞いだ入口で守る | 試作だけ |
| 発つ朝 | 襲撃の跡が残る | 襲撃で壁と置き物が壊れ、血の跡と瓦礫が残る | 置物は壊れて残骸になる |
| 発つ朝 | 世話になった | 数日の暮らし。手をかけた建物を置いていく | 無い |
| 発つ朝 | 次へ行こう | 北の土地ほど寒く、良い物がある。報酬は、次のより寒い土地へ踏み込む鍵になる | 北ほど寒く危険度が上がるが、報酬の差は見えない |
| 発つ朝 | もう留まれない | 襲撃を越えたら発つ。近くの施設も尽きていく | 無い |

### 守る条件

design.md の方針と、この議論で決めた条件。

- 恒久の拠点は持たない。拠点を整えても、ずっと住めるようにはしない。整えることは時間を買う物で、ずっとの安全は買えない
- 厳しさはプレイヤーの強さでなく、場所と時で決まる。襲撃の強さは、錨の位置の北の深さで決める
- 襲撃の周期は、錨に関わらず挑戦全体の暦で回す。錨の無い夜に来た襲撃は、野ざらしで受ける
- 圧は間欠的にする。普段は余裕を持たせ、長居のときだけ切迫させる
- 留まることを、ただ待つだけで得をする遊びにしない。錨の燃料の吸い上げは詰みを防ぐ量にとどめる
- 拾える物には限りがあり、湧き直さない。鍵になる物は湧かない
- 夜は、視界の外と、塞いでいない所の外に敵が湧く。見えている所と、塞いだ建物の中には湧かない。湧くのは少数がうろつく程度で、群れが拠点を狙う襲撃とは大きさで分ける
- 湧く敵は良い物を落とさない。湧く獣は食べ物を落とすが、食べ物は腐るので、積み上げて次のエリアへ持ち越しきれない
- 運ぶか置いていくかに例外を作らない。全部を畳めるが、重い物は燃費が割に合わないので置いていく
- 建物は建てない。壁、床、扉のタイルは置かない。置けるのは置き物だけで、向きは持たない。直すことを土台にし、置き物で塞ぐ、守る、暮らしの設備を置く
- キューブは暮らしの道具を運ぶ物で、錨になる。家ではない。勝手について来る。主役は人で、運転はしない
- 地下は作らない
- ソロのターン制で、群れと1手ずつ戦う重さを強いない。前の試作で、機銃で群れを受ける手触りがよいことは確かめてある

### 1つの土地での暮らしに要ること

- やることがある。遠征、加工、狩り、建物の修理と整え
- 発つ理由がある。次の土地の方が良い報酬がある。近くの施設もいずれ尽きる
- 備える理由がある。暦どおりに襲撃が来る
- 残りが見える。次の襲撃が何日後かと、近くの施設の残りの見当を、プレイヤーが知れる
- 詰まない。燃料が尽きても、錨を下ろしていればゆっくり戻る。キューブを失っても核から作り直せる

### 拠点の整え方

家の中身は連れ歩き、殻は土地ごとに借りる。建物の形の種類は手で描く絵の数で決まり、多くは出せないので、形の違いでは選ばせない。どこに錨を下ろすかは、区域の性質の得と損で選ばせ、判断の重みの残りは、その建物をどう整えるかに置く。

| 整え方 | 選択 | 得と損 |
|---|---|---|
| 壊れた所を直す | どの壁、扉、窓を直して使うか | 直すほど暖かく守りやすいが、材料を食う |
| 置き物で塞ぐ | どの窓と扉を塞ぎ、どこを開けておくか。建物の外に守りの線を作るか | 塞ぐほど守りやすいが、暗く、出入りが不便になる。開けておいた入口へ敵を集め、機銃を向けられる |
| 部屋を捨てる | 壊れた部屋を直すか、塞いで捨てて狭く暮らすか | 狭いほど暖かく守りやすいが、置ける物が減る |
| 設備を置く | 暖房、寝床、工作台、機銃を、どの部屋のどこに置くか | 暖かい奥に暮らしを、入口側に守りを置く |

- 場所選びの得と損は、建物の形でなく、区域の性質から出す。区域ごとに、建物の固さ、夜に湧く敵の強さ、湧く獣の多さ、近くの施設の良さが違う

| 場所の例 | 得 | 損 |
|---|---|---|
| 研究所 | 建物が固い。近くに良い物がある | 夜に湧く敵が強く、安心できない |
| 山小屋 | 獣が湧き、食べ物を得やすい | 建物が脆い。近くに良い物が少なく、鍵が揃いにくい |
| 市街地の家 | 手頃な固さ。施設が近い | 湧く敵が多く、四方から来る |

- 誰がやっても同じ拠点にならない。限られた材料をどこに使うかで、拠点の形がプレイヤーごとに変わる
- 多様さは建物の形に頼らず、壊れ方、周り、巡ごとの状況の掛け合わせから出す。壊れ方は建物ごとに生成で変える。巡ごとの状況の中心は、予告される襲撃の種類で、敵の来る方角と動き方で、塞ぐ所が変わる
- 置き物の種類は少なくし、種類の多さで遊ばせない。材料と重さで数を絞り、置きまくる作業にしない
- 暖まりやすさは室内の気温と体温へ、静かな所は眠りの質へ、広さは置ける設備の数へ流す。居心地値のような1つの数は作らない

### 報酬の法則

- 北の土地ほど寒く、拾える物も良い。報酬の差は、見て分かるようにする
- 報酬は、強くなること自体でなく、次のより寒い土地で暮らし、乗り切るための鍵にする。鍵を得ると次の土地へ踏み込め、その土地がまた次の鍵をくれる
- 鍵の形は3つで、互いを補う。どれかが足りなくても、他で補って進める
  - 運べる暮らしの道具。強い暖房や断熱で、より寒い土地の建物でも暖かく暮らせる
  - 人体改造。体が寒さに強くなり、外で動ける時間が延びる
  - 装備。防寒具で外の活動を、武器と機銃で襲撃を越える
- キューブは運ぶ器で、燃料という維持の手間を持つ。旅の燃料は、主に遠征で持ち帰った物から得る

### 確かめる順番

作る前に確信までは持てない。置いている前提を分け、危うく、安く確かめられるものから順に確かめる。

| # | 前提 | 危うさ | 確かめ方 |
|---|---|---|---|
| 1 | 拠点の整え方が毎回違う判断になる | 高い | コードを書かずに確かめる。今ある建物の絵を紙に写し、壊れ方と襲撃の種類の札を引き、限られた材料でどこを直し、塞ぐかを何度か試す |
| 2 | 報酬が次へ行こうと思わせる | 高い | コードを書かずに確かめる。北の土地ごとの報酬の差を表に並べ、行きたいと思えるほどの差かを見る |
| 3 | 留まるほど赤字になる | 高い | 今ある測る道具で、エリアから得られる物と、暮らしと襲撃で減る物を1日ごとに比べる。錨の吸い上げだけで暮らせないことも確かめる |
| 4 | 帯の9×9に、遠征先の施設が入る | 中 | 地図の画像を書き出し、錨を下ろしそうな位置から届く施設を数える。広さと時間の釣り合いは、遊びながら調整する |
| 5 | 外の寒さと中の暖かさの落差が、居心地として感じられる | 中 | 今の寒さと体温の仕組みのまま、手で作った建物に暖房を1つ置き、吹雪の夜を1晩過ごす |
| 6 | 襲撃の準備が報われ、乗り切った手応えがある | 低め | 捨てる前提の試作で、手触りがよいことを確かめてある |
| 7 | 発つ朝に名残惜しさを感じる | 一番高い | 短い試作では出ない。1から6が通った後、作り込む前に、1つの拠点で数日を通しで遊ぶ |

7 を関門にする。数日の通しの遊びで名残惜しさが出なければ、作り込む前に方向を見直す。

### 数字の目安

| 項目 | 目安 | 状態 |
|---|---|---|
| 襲撃の間隔 | 固定。数日に1度 | 日数は未定 |
| エリアの数 | 10くらい | 脱出で終わる |
| 1つのエリアに留まる日数 | 襲撃の周期と同じ | 襲撃1回で発つと仮に置いた |
| 挑戦の長さ | 周期7日なら、ゲーム内で70日くらい。1日は1500ターン | 実時間で何時間かは測っていない |
| エリアの広さ | 帯の9×9チャンク。1チャンク24タイル | 拠点から端まで約100タイルで、1日の時間に比べて小さい。遊びながら調整する |
| 1日に要る食べ物 | 満腹1回の 500 | 今の仕組みの値 |
| 1日に要る燃料 | 地面の焚き火を1日もたせる熱量 3000、木で約15kg | 今の仕組みの値 |
| 錨の吸い上げ | 詰みを防ぐ量。遠征で持ち帰る量よりずっと少ない | 未定 |
| 1回の旅の距離と燃料 | 新しい土地は拠点から5チャンク北から始まる | 燃料は未定 |

### 決めたこと

- 1つのエリアに錨を下ろし、遠征を繰り返し、襲撃を乗り切ったら北へ発つ一巡を、遊びの芯にする
- キューブの展開が錨になる。錨の間は帯が止まってエリアになり、端は越えられない。設備は錨の間だけ働く
- 錨の間、キューブは燃料をゆっくり吸い上げる。詰みを防ぐ量にとどめ、遠征の方がずっと多く得られる
- 旅は北への一方通行。その場の世界は作り直さない
- 襲撃は錨に関わらず挑戦全体の暦で来る。強さは場所の北の深さで決める。1つのエリアで越える襲撃は1回と仮に置く
- 夜は敵が湧き、漁り尽くしても安全にならない。湧く敵は良い物を落とさない。場所選びの得と損は区域の性質から出す
- 報酬は、次のより寒い土地へ踏み込む鍵にする。鍵の形は、運べる暮らしの道具、人体改造、装備の3つで、互いを補う
- 建物は建てない。置けるのは向きの無い置き物だけで、直すことを土台にする
- 建物の形の違いでは選ばせない。場所は区域の性質の得と損で選び、限られた材料での整え方に判断の重みを置く
- 前提を分け、危うく安く確かめられるものから順に確かめる。数日の通しの遊びを、作り込む前の関門にする

### 決める問い

設計に入る前に、次を決める。重い順に並べる。

1. 鍵が揃ったことを、プレイヤーがどう知るか。次の土地の寒さを、遠くの吹雪の見た目や北風の冷たさのような身体の訴えで見積もれるようにする
2. 襲撃の周期の日数
3. エリアごとの違いを何で出すか。主な施設の種類で、遠征の中身と手に入る鍵が変わる形が候補
4. 脱出の手段は何で、どこでどう直すか。各エリアの鍵と、どうつながるか
5. 燃料を何に使うか。錨の間の暖房などの設備が燃料を食うなら、暖かく過ごすことと次の旅の燃料が取り合いになる
6. 遠征で持ち帰る量を、人の手の重さだけで決めるか。往復が作業にならないか
7. 70日が実時間で何時間になるか。眠りや待ちで進む分を除いた操作の時間を測り、エリアの数と周期を合わせる
8. 遠征先の施設が帯の中に入るよう、生成で手当てするか。入らないエリアでは旅を続けさせるか
9. 錨の上げ下ろしと北への旅に、手番と燃料をどれだけかけるか
10. 夜に湧く敵と獣の量と強さを、区域ごとにどう決めるか
11. 襲撃を越えると何が得られるか。弾と修理の材料を減らすだけの税にしない
12. 目標を誰が出すか。世界は無人で、依頼を出す人がいない。救難信号や古い記録など、物が目標を語る形が候補
13. 襲撃の種類を何にするか。種類ごとに、塞ぐ所が変わるようにする
14. 置き物の種類と材料。敵がそれをどう壊しに来るか。今の敵は道を探さない
15. 壊れ方をどう生成するか。今の施設の絵の上に、壊れた壁、扉、窓をどう散らすか
16. 1日の過ごし方の例。朝から夜までに何をするか
17. 罠は待つだけで実るか。待つだけで得をしない条件とどう両立させるか
18. 近くの施設の残りと、次の襲撃までの日数をどう見せるか
19. 襲撃が暮らしの合間の試練にとどまり、拠点防衛の遊びに寄りすぎないか

## 設計

この文書は要件を決める場にする。要件の決める問いに答え、確かめる順番の前提を確かめた後、仕組みごとに別の設計ドキュメントで設計を書き起こす。

## 採用しなかった方法

| 案 | 採らなかった理由 |
|---|---|
| 天候だけの災厄 | 備えが済めばこもって待つだけになり、うまく備えるほど退屈になる。天候は後で襲撃の性格を変える味付けに回す |
| 人が群れと1手ずつ戦う | ソロのターン制では手数が重く、同じ判断を何十回も繰り返す |
| 戦闘を数値で即決する | 準備の値打ちが見えにくい。試作で、押し寄せるのを見る緊張に手応えがあった |
| 機銃を置いていく物にする | 毎回の準備は重くなるが、運ぶ暮らしの道具を育てる手応えが薄れる |
| 置いていく物に固定の印を付け、圧縮から外す | 例外が増えて分かりにくい。重さで割に合わないから置いていく方が、選ぶ自由も残る |
| 運転型のキューブ | 主役は人にしたい。運転は不自然で、作るのも重い |
| 地下の施設を守る | ruins では地下を作らない |
| 燃料だけを締める | 移るのが面倒になるだけで、留まる理由は生まれない |
| 家の温まり | 家が住むほど暖まるという理由が不自然だった |
| 土地勘や段取りで能率が上がる | 留まるほど楽になり、厳しさが削れる |
| 設備の能率を留まるほど上乗せする | 留まるほど楽になりすぎる。暖機運転は、上限を今の能率にする形でだけ後の候補に残す |
| 尽きることだけを圧にする | 漁り尽くした土地でも、固めた拠点に安全に居座れて、緊張にならない。暦の襲撃と組み合わせる |
| 拾える物を増やすだけ | 拾って移るのが速くなるだけ |
| 留まるほど敵が気づいて寄ってくる気配 | 予告付きの襲撃の方が、備える日数が見えて準備を楽しめる |
| 土地を区切り、間を俯瞰図の旅にする | 留まる・移るのリズムは一番はっきりするが、地続きの世界を作り直す大きな変更になる。錨で帯を止めれば、ほぼ同じことが小さく作れる |
| 通った所の変化を保存し、どの方向にも戻れる世界にする | セーブが育ち続ける。前の拠点に戻れて、発つ朝が別れにならない |
| 錨の間に燃料が多く貯まる | 待つだけで得をし、無限の稼ぎの入口になる。詰みを防ぐ量にとどめる |
| 錨を下ろした時だけ襲撃が来る | 錨を下ろさない方が得になる |
| 壁や床のタイルを置く建設 | 拠点防衛の建設は、壁や罠の種類、置き場の操作、敵の経路まで揃えないと満足させられず、作るのが沼になる。置き物だけにする |
| 建物の形の違いで拠点を選ばせる | 建物の形の種類は手で描く絵の数で決まり、数巡で覚えてしまう。性質の得と損を付けても、形が少ないと毎回同じ選択になる |
| 直すのは壊れた所を元に戻すことだけに絞る | 誰がやっても同じ拠点になり、自分で整えた居場所と感じにくい |
| 殻に居心地値の1つの数を持たせ、バフをかける | 居心地値が一番高い建物を選べばよい、になり、最強の1つを選ぶ問題が残る。数を前に出すのは、身体の訴えで感じさせる方針とぶつかる |
| 報酬の中心を1つの種類に絞る | 1つが足りないと進めなくなり、自分なりの生き方の幅が狭まる。種類でなく、次の土地へ踏み込む鍵という役目で決める |
| 研究所は寒いので拠点にできない、のような決まりを足す | 決まりは理不尽に感じる。広く窓の割れた建物は暖まりにくい、という性質から寒さが出る形にする |

## コメント

- 着想は、血の月の夜に襲撃が来て拠点を固める遊びと、波の間に資源を掘って守る遊びである。どちらもソロで成り立っている
- 一巡と報酬の着想は、7 Days to Die と Cataclysm: Dark Days Ahead である。危険な場所ほど良い物があり、報酬が次のより危険な場所へ踏み込む力になる、という形が共通している
- 試作は `proto/base-raid` にある。機銃3基でもキューブの HP 200 を守り切れなかった。数値の釣り合いは正式に組んでから詰める
- 地上に置いた置き物が、保存と読み込みをまたいで残るかは確かめていない。拠点に数日いる間は残らないと困る
- 後で足す候補は、天候の味付け、前触れを読む知識、暮らしが敵を呼ぶ仕組み、怪我と病の療養、暖機運転である
- 土地が何日もつかの数字は、開始の行の近くだけの値で、北の奥では違うかもしれない。測るのに使ったテストはコミットしていない。`internal/balance` の指標として残すのがよい
