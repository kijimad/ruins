# 手榴弾を爆ぜさせ、毒と炎を効かせる

## 背景

投げるの設計 261121121220 では、手榴弾3種を狙った敵1体に当てるだけにし、爆風の範囲と毒・炎の効果を後回しにした。手榴弾の説明文は「爆風と破片で」「毒を広げる」「広い範囲に炎」と書いていて、今の挙動と食い違っている。

手榴弾は、弾や銃が無くても複数の敵を一度に削れる手になる。範囲が自分や味方にも及ぶなら、どこで投げるかが判断になる。

## 要件

- 手榴弾は命中の判定をせず、狙った敵のマスで必ず爆ぜる
- 爆ぜたマスと周り8マス、つまり 3×3 にいる者すべてに効く。自分・随伴するキューブ・置物も含む
- 毒手榴弾は、爆風に入った者に毒の不調を付ける
- 火炎手榴弾の爆風は火の属性を持ち、火への耐性で軽減される
- 煙幕弾と閃光弾は、この doc では扱わない

## 設計

### 投げの欄の爆風

投げの欄に爆風を足す。爆風を持つ物は、命中の判定をせず狙ったマスで爆ぜる。

```cue
#Throw: {
	damage!:   #BaseDamage
	accuracy!: #Accuracy

	// 爆ぜる物の爆風。持つ物は命中の判定をせず、狙ったマスで爆ぜる
	blast?: #Blast
}

// 爆風。爆ぜたマスから radius マスまでの者すべてに効く
#Blast: {
	radius!: #BlastRadius

	// 爆風の属性。省くと無属性
	element?: #Element

	// 爆風に入った者に付ける不調
	condition?: #ConditionTypeName
	if condition != _|_ {
		condition_ref: _conditionIDs[condition] @rawgen(-)
	}
}

// 爆風の半径。マス数
#BlastRadius: int & >=1 & <=3
```

```go
// ThrowAttack は物を投げたときの攻撃の値
type ThrowAttack struct {
	Damage   int
	Accuracy int
	Blast    *Blast // 爆ぜる物だけが持つ
}

// Blast は爆風の値
type Blast struct {
	Radius    int
	Element   rawschema.Element
	Condition ConditionType // 空なら不調を付けない
}
```

`ThrowAttack.GetElement` は、爆風があればその属性を返す。

物ごとの値は次の案にする。

| 物 | damage | radius | element | condition |
|---|---|---|---|---|
| 手榴弾 `grenade` | 20 | 1 | 無し | 無し |
| 毒手榴弾 `poison_grenade` | 10 | 1 | 無し | 毒 `venom` |
| 火炎手榴弾 `flame_grenade` | 25 | 1 | 火 `FIRE` | 無し |

毒手榴弾は毒で削るので、爆風の威力を下げる。

### 毒の不調

raw の不調の表に毒 `venom` を足す。全身にかかり、時間で治る。痛みと身体機能の低下があり、重いと血が減る。部位の欄 `parts` は攻撃で負う怪我の部位を選ぶためのものなので書かない。食中毒と同じく、付けるときに全身の部位へ置く。

```toml
[[conditions]]
  bloodDropPerSeverity = 15
  bodyFuncDropPerSeverity = 10
  cause = "illness"
  description = "Venom is spreading through the body. It clears on its own over time."
  id = "venom"
  name = "Venom"
  painPerSeverity = 4
  recoverPer = 1
  recovery = "recover_over_time"
```

爆風に入った者のうち `HealthStatus` を持つ者に、全身の部位へ中等度の毒を付ける。すでに毒があれば重ねず、重いほうを残す。

### 爆ぜる処理

投げる行動の DoTurn で、爆風を持つ物は次の流れにする。

1. 狙った敵のマスを爆ぜる中心にする
2. 中心から縦横斜めに radius マス以内のマスにいる、HP を持ち死んでいない者を集める。集めてから効かせる
3. 集めた者それぞれに、命中の判定をせずダメージを計算して与える。ダメージの計算は射撃と同じ `calculateDamage` を使い、属性の耐性が効く。会心は出さない
4. 不調を持つ爆風なら、`HealthStatus` を持つ者に不調を付ける
5. 投げた物を消す

爆風のダメージで投擲のスキルが伸びるのは、投げた本人がだれかを傷つけたときに1回だけにする。爆風が当たる者には、怪我の抽選をしない。破片の傷は爆風のダメージに含める。

集める前に中心の座標を取るので、爆風で倒れた敵の後始末に頼らない。

### 狙う画面

爆風を持つ物を狙うときは、命中率の代わりに「Blast」と出す。射程と射線の判定は今のまま使う。

### 使い道の統計

`item_uses_test.go` の「投げる」は今のまま、投げの欄を書いた物を数える。

## 採用しなかった方法

- **命中の判定で着弾点をずらす**: 着弾点の決め方が増える。手榴弾は狙ったマスで必ず爆ぜる形で足りる
- **周り2マスまで効かせる**: 強すぎ、自分を巻き込みやすい。半径は欄で物ごとに変えられる
- **敵だけに効かせる**: 爆弾を近くで気軽に投げられる。仕組みは誰にでも同じに働く
- **炎で範囲の置物に火を付ける**: 燃え広がりまで入れると範囲が広がる。火の属性のダメージで炎を表す
- **毒を今回は入れない**: 毒の不調は raw の行の追加だけで足せる
