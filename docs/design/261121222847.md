# 手榴弾を爆ぜさせ、毒と炎を効かせる

## 背景

投げるの設計 261121121220 では、手榴弾3種を狙った敵1体に当てるだけにし、爆風の範囲と毒・炎の効果を後回しにした。手榴弾の説明文は「爆風と破片で」「毒を広げる」「広い範囲に炎」と書いていて、今の挙動と食い違っている。

手榴弾は、弾や銃が無くても複数の敵を一度に削れる手になる。範囲が自分や味方にも及ぶなら、どこで投げるかが判断になる。

## 要件

- 手榴弾は命中の判定をせず、狙った敵のマスで必ず爆ぜる
- 爆ぜたマスと周り8マス、つまり 3×3 にいる者すべてに効く。自分・随伴するキューブ・置物も含む
- 毒手榴弾は、爆風に入った者に毒の不調を付ける。毒は時間で治り、痛みと身体機能の低下がある
- 火炎手榴弾の爆風は火の属性を持ち、火への耐性で軽減される
- 煙幕弾と閃光弾は、この doc では扱わない

## 設計

### 投げの欄の爆風

投げの欄に爆風を足す。爆風を持つ物は、命中の判定をせず狙ったマスで爆ぜる。

```cue
#Throw: {
	damage!:   #BaseDamage
	accuracy!: #Accuracy

	// 爆ぜる物の爆風。持つ物は命中の判定をせず、狙ったマスで爆ぜる
	blast?: #Blast
}

// 爆風。爆ぜたマスから radius マスまでの者すべてに効く
#Blast: {
	radius!: #BlastRadius

	// 爆風の属性。省くと無属性
	element?: #Element

	// 爆風に入った者に付ける不調
	condition?: #ConditionTypeName
	if condition != _|_ {
		condition_ref: _conditionIDs[condition] @rawgen(-)
	}
}

// 爆風の半径。マス数
#BlastRadius: int & >=1 & <=3
```

```go
// ThrowAttack は物を投げたときの攻撃の値
type ThrowAttack struct {
	Damage   int
	Accuracy int
	Blast    *Blast // 爆ぜる物だけが持つ
}

// Blast は爆風の値
type Blast struct {
	Radius    int
	Element   rawschema.Element
	Condition ConditionType // 空なら不調を付けない
}
```

`ThrowAttack.GetElement` は、爆風があればその属性を返す。

物ごとの値は次の案にする。

| 物 | damage | radius | element | condition |
|---|---|---|---|---|
| 手榴弾 `grenade` | 20 のまま | 1 | 無し | 無し |
| 毒手榴弾 `poison_grenade` | 15 から 10 | 1 | 無し | 毒 `venom` |
| 火炎手榴弾 `flame_grenade` | 25 のまま | 1 | 火 `FIRE` | 無し |

毒手榴弾は毒で弱らせるので、爆風の威力を下げる。

### 毒の不調

raw の不調の表に毒 `venom` を足す。全身性で、時間で治る。痛みと身体機能の低下がある。

```toml
[[conditions]]
  bodyFuncDropPerSeverity = 10
  description = "Venom is spreading through the body. It clears on its own over time."
  id = "venom"
  name = "Venom"
  painPerSeverity = 4
  recoverPer = 1
  recovery = "recover_over_time"
```

毒は時間とともに軽くなる一方で、重症に届かない。重症でだけ効く血の減りと死因の欄は効かないので書かない。部位の欄 `parts` は攻撃で負う怪我の部位を選ぶためのものなので書かない。

毒は HP を直には削らない。不調が HP を減らすのは、血液量を下げて危険域を下回らせる体の経路だけにする。毒にだけ HP を直に削る欄を足すと、この経路を迂回する例外が1つの行のためにできる。毒で HP を減らすなら、血液量を下げる形で足す

付けるのは、食中毒と同じ `gameaction.ContractIllness` を使う。全身性の不調を胴の1部位に置き、同じ不調が発症中なら重ねない。初めは軽度の進行度で始まる。毒が発症している者に2発目が当たっても、進行度は延びず、爆風のダメージだけになる。発症が終わって進行度だけ残っている者には、発症したての進行度で付け直す。`HealthStatus` を持たない者は飛ばし、プレイヤーには「毒にかかった」のログを出し、身体機能の再計算を促す。全部位に置くと、痛みと身体機能の低下が部位の数だけ重なるので、置かない。

### 爆ぜる処理

`applyAttackDamage` を、命中の判定と、命中したあとに与える処理に分ける。命中したあとに与える処理を `applyHit` とし、射撃・近接・投げる・爆風が共有する。`applyHit` はログ・ダメージ・見た目の効果・置物の廃材・被弾した者の行動の中断をまとめて行い、怪我の抽選とスキルの伸びは引数で切り替える。

```go
// applyHit は命中した攻撃を target に与え、与えたダメージを返す
func applyHit(actor, target ecs.Entity, world w.World, attack gc.Attacker, name i18n.Msgid, opts hitOptions) (int, error)

// hitOptions は命中したあとの処理のうち、呼ぶ側が決める部分
type hitOptions struct {
	critical  bool // 会心
	injury    bool // 怪我を抽選する
	growSkill bool // スキルを伸ばす
	damageMod int
}
```

射撃と近接は、命中の判定のあと `growSkill` を真にして呼ぶ。爆風は `growSkill` を偽にして対象ごとに呼び、返ったダメージを見て、呼ぶ側でスキルを1回だけ伸ばす。

投げる行動の DoTurn で、爆風を持つ物は次の流れにする。

1. 狙った敵のマスを爆ぜる中心にする。爆風を持つ物は、威力に関わらずこの流れに入る。威力 0 の物を攻撃として扱わない分岐より先に判定する
2. 中心から縦横斜めに radius マス以内のマスにいる、HP を持ち死んでいない者を集める。集めてから効かせる。壁は爆風を遮らない。半径が小さいので許す
3. 集めた者それぞれに、命中の判定をせず、会心も出さずに `applyHit` で与える。怪我の抽選はしない。破片の傷は爆風のダメージに含める
4. 不調を持つ爆風なら、`ContractIllness` で不調を付ける。`ContractIllness` がログを出すのはプレイヤーのときだけなので、ほかの者が不調にかかったら、爆風の側で「〜は毒にかかった」をログに出す。毒手榴弾の効き目がプレイヤーに見えるようにする
5. 投げた物を消す

投擲のスキルが伸びるのは、投げた本人が自分以外の者を傷つけたときに1回だけにする。傷つけた相手のうち、投げた本人と随伴するキューブは数えない。自爆を繰り返してスキルを稼げないようにする。

投げた本人も範囲に入るので、爆風で倒れることがある。倒れても、投げた物を消して行動を終える流れはそのまま通す。

### 狙う画面

爆風を持つ物は命中の判定をせず必ず狙ったマスで爆ぜるので、命中率を 100% と出す。射程と射線の判定は今のまま使う。

## 採用しなかった方法

- **命中の判定で着弾点をずらす**: 着弾点の決め方が増える。手榴弾は狙ったマスで必ず爆ぜる形で足りる
- **周り2マスまで効かせる**: 強すぎ、自分を巻き込みやすい。半径は欄で物ごとに変えられる
- **敵だけに効かせる**: 爆弾を近くで気軽に投げられる。仕組みは誰にでも同じに働く
- **炎で範囲の置物に火を付ける**: 燃え広がりまで入れると範囲が広がる。火の属性のダメージで炎を表す
- **毒を今回は入れない**: 毒の不調は raw の行の追加だけで足せる
- **毒が HP を直に削る欄を足す**: 試したが外した。不調が HP を減らす経路は血液量だけにそろえており、毒だけの例外になる。効き目は「毒にかかった」のログと爆風のダメージで見える
