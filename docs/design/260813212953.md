# コアの方向整理と、検証を設計判断より先に置く方針

## 背景

ruins が他のインディーと比べてインパクトと identity に欠ける、という問題意識から議論を始めた。移動拠点の見せ方、さらに戦闘の要否まで遡って再考した。

掘り下げた末の最重要の認識は、**コアメカニクスの面白さがまだ検証されていない**ことだった。そのため設計判断が抽象論の中でぶれ続ける。抽象空間ではどの案も等しくもっともらしく聞こえ、「面白い」「面白くない」の非対称は実際に遊ばないと現れない。コードを make check で検証するのと同じで、コアは遊んで検証する以外に確かめようがない。

この doc は議論の整理であって結論の固定ではない。次の一手を「理論の追加」でなく「コアの検証」に定めるための足場とする。

## 要件

議論から抽出した、移動拠点とコアが満たすべき抽象条件。Hard は満たさねば ruins でない、Soft は最大化したい、Anti は踏んではいけない罠。

**Hard**

- 持続しカスタム可能な内部空間を持つ。内部を別ステージにする設計は実装が楽で自由度が高い
- 家を連れ歩く。移動拠点が自分と共に動く感触を保つ
- 一方向で後退は死。戻れる網や循環を作らない
- 移動コストは積載に依存する。重さがコストを決め、何を残すかが決断になる
- footprint は 1x1、自由歩行の単一解像度ワールドを壊さない

**Soft**

- 署名イメージ。一目で読め、他で見ない外観。これがインパクトの源
- 家への愛着。喪失が効く関係
- 冷気に呑まれた世界、暖が生である premise と一致する
- 演出できる瞬間を持つ
- 収集コアとの統合。収集が家の成長に直結する

**Anti**

- 乗り物にしない。車や列車は競合が多く既視感が強い
- あらかじめ在る容れ物を動かし内部を飾るだけの骨格の着せ替えにしない
- 素の異次元ポケットを付け足すだけにしない

## 設計

現時点の傾き。いずれもコア検証を通してから確定する未検証の仮説である。

**1. 移動拠点の見せ方**

「あらかじめ在る容れ物を動かす」骨格を壊し、家を「道中で漁った物が凝集して育つもの」にする。footprint は 1x1 のまま、成長は見た目の密度で表す。据えて休むと暖が広がり、扉が内部の別ステージへ繋がる。これにより収集と家が一体化し、何を拾ったかで毎ラン一点物のシルエットになる。無地のキューブの弱点はシルエットが無く記憶に残らないことで、集積した記念碑はそれを解く。

**2. 戦闘の位置づけ**

戦闘をコアから降ろし、稀で致命的な回避対象にする。押し返す敵対性は、寒波前線と兵station、競合や腐敗といった「反応する系」が担う。戦闘が供給していた機能を機能単位で分解すると、失敗と成功、リスクとリターン、難易度調整、普遍性は寒波と兵站が既に供給しており、戦闘を抜いて失うのは速い手応えと押し返す敵対性とスペクタクルの3つに絞られる。このうち代替が最も難しい押し返す敵対性を、生死の対戦でなく環境と所有コストの抵抗へ移す。

コア動詞は「漁る、重量で取捨する、家に組み込む、呑まれる前に前へ運ぶ」。緊張は戦闘死でなく喪失から来る。重くて全部は持てず、背後は凍って戻れない。

**3. 差別化の芯**

均衡が不可能であること。留まれば呑まれ、前進しかできず、背後の世界は消える。安住を目指すのでなく、どこまで行けるかを問う。勝利状態を持たず到達距離を記録とする既存方針と一致する。多くのサバイバルが安定した籠城の高原に達せるのに対し、ruins はその高原を禁じる点が固有の情感を生む。

**4. 検証を設計判断より先に置く**

上の1から3は全て未検証の仮説である。skin とテーマと戦闘の是非は、検証済みで面白いコアを増幅するかで後から決まる。次の一手は、アートとテーマと戦闘を剥いだ最小の遊べる形で、「何を残すかの決断が毎ループ面白いか」を実測すること。装飾ゼロでも悩ましい良い決断があり、もう一度やりたいと感じるなら、コアは本物であり着飾る意味が生まれる。感じないなら、どの skin も救わないので仮説を替える。検証済みのコアが1つ固定されれば、以降の判断に基準ができ、ぶれが止まる。

## 変更箇所

本 doc は方向整理と検証方針であり、実装の変更箇所はコア検証の結果で確定する。現時点で確定した変更箇所は無い。

## 採用しなかった方法

- **無地のキューブを押す、すなわち現状**。Hard は満たすが署名イメージとインパクトが無い。骨格が容れ物と装飾のままで、外観が記憶に残らない。
- **車やバン**。一目で読めるが既視感が強く競合が多い。内部の広さと外観サイズの不一致で、別ステージ内部が嘘くさく見える。
- **現実的な橇や荷役の獣**。読めて情感もあるが、歩ける内部空間を現実には持てず、結局超常が要る。
- **素の異次元ポケット**。ひねりが無く、容れ物の着せ替えに留まる。内部が拾った物で出来ているという統合が無ければ手垢のまま。
- **列車**。レールが前へのみ進む点でテーマは強いが、自由歩行の単一解像度ワールドを捨てる代償が重く、別ゲームになる。
- **散在するアクセス点で同一内部へ繋げる**。内部アクセスは綺麗だが、連れ歩きの感触を失う。行き来できると後退は死と衝突し、消える設計にすると連れ歩きの芯も失う。

## コメント

- この doc は結論でなく現状の整理である。最大の学びは、抽象議論を重ねるほどぶれること、コアの面白さは遊んで検証する以外に確かめられないこと。
- 傾きとしては、集積する家と暖の据え置き、戦闘は稀な劇物、均衡の不可能さを芯に、の3点。ただしいずれもコア検証を通してから確定する。
- 検証で「何を残すかの決断」が装飾ゼロで面白いと分かれば、以降の skin とテーマと戦闘の判断に基準が生まれ、ぶれが止まる。面白くなければ仮説を替える。
- 外部作品を枠組みには据えない。サバイバルで戦闘を稀な劇物に留める先行例はあるが、ruins 固有の差は均衡が不可能な点にあり、そこを自前の機構として設計する。
