# 最小のゲームループを完成させる

## 背景

ruins には空腹・寒さ・怪我・天候・焚き火・家の探索・北進が一通りそろっているが、遊んでも判断が生まれず、ありがちなサバイバルに見える。仕組みは足りているのに、ループの部品が4つ欠けている。

**向かう先が無い。** 負けの条件はゲームオーバーとしてあるが、勝ちの条件が無い。北へ進むほど寒くなり、`latitudeColdForDepth` が1チャンクごとに1℃下げる。危険度も `DangerLevelForDepth` が3チャンクごとに上げる。北へ進む見返りが無いので、進む理由が無い。参考 codebase: `internal/world/query/temperature.go`、`internal/world/query/danger.go:31`。

**急ぐ理由が弱い。** 季節は32日で1周し、冬の底は -30℃ になる。参考 codebase: `internal/components/game_time.go:88-92`。冬の到来という締め切りは既にあるが、ゴールが無いので、何に間に合わせるのかが無い。

**漁ることが安全すぎる。** #945 で建物の中に施設の敵を置けるようになった。施設ごとのリスクとメリットの差は doc 261108165219 で進めている。

**作る段が途切れている。** 集められる素材と、レシピが使う素材が `iron` 以外重ならない。

| | 素材 |
|---|---|
| 分解で手に入る素材 | `firewood` `branch` `stone` `sharp_stone` `scrap_iron` `iron` `rusted_chain` `electric_wire` `cord_bundle` |
| レシピが使う素材 | `wooden_stick` `iron` `ferrite_core` `green_herb` `yellow_herb` `ashes` `crystal_powder` |

木の剣と鉄のナイフの材料 `wooden_stick` は、武器のグループ `early_melee_weapon` と `tree_spirit` のドロップからしか出ない。武器を作る材料が武器と同じ場所でしか拾えない。木と岩の分解には伐採と採掘の道具が要り、序盤は持っていない。避難民と医者は武器を持たずに始まる。結果として、序盤の武器が運で決まり、進行が安定しない。

## 要件

1. 北の目的地に着くとクリアになる。HUD に残りの距離が出る。
2. 冬が来る前に目的地へ着くことが目標になる。同じ場所に留まるほど、冬が近づき、周りの物資が減る。
3. 中身の多い建物ほど危険になる。漁るたびに、もう1軒行くか北へ発つかを決める。
4. 道具を持たずに始めても、茂みと木箱から最初の武器と道具が作れる。作った道具で木と岩が開き、次の素材が取れる。

## 設計

### 1. 北の目的地とクリア

```go
// goalDepthChunks は湧き位置から目的地までの北進チャンク数。冬の底までに着く距離に合わせて振る
const goalDepthChunks = 30

// ReachedGoal は y が目的地の深さに達したかを返す
func ReachedGoal(world w.World, y consts.Tile) bool {
	return NorthDepthChunks(world, y) >= goalDepthChunks
}
```

- 北への深さは既存の `NorthDepthChunks` で測る。HUD の奥地の表示も同じ関数を使っているので、そこに残りの距離を足す。
- プレイヤーが目的地の深さに入ったら、ゲームオーバーと同じ形でクリアの画面へ移る。
- 目的地に特別な施設や景色を置くのは、ループが回ってから考える。最初は深さの線を越えるだけにする。

### 2. 冬という締め切り

- 新しい仕組みは足さない。既存の季節の気温で、冬の底が -30℃ になることを締め切りとして使う。
- `goalDepthChunks` は、まっすぐ進めば秋のうちに着き、寄り道を重ねると冬に捕まる距離に振る。値は実プレイで決める。
- 建物の中身は一度漁ると戻らない。留まれば周りの物資が減る。これは今の作りのままで成り立つので、統合テストで確かめるだけにする。

### 3. 漁ることのリスク

- 施設ごとの敵と戦利品の差は doc 261108165219 に任せ、この doc では重ねて設計しない。
- この doc では、序盤の家に敵がいる割合が、武器を作れる前提で釣り合っているかを確かめる。4の作る段ができるまでは、武器なしで家に入ることになるためである。

### 4. 序盤の作る段

道具なしで取れる素材から始め、作った道具で次の素材を開く。

```
茂み → branch ─→ wooden_stick ← branch x2
木箱・冷蔵庫 → scrap_iron
wooden_stick x2 → wooden_sword
scrap_iron x2 + wooden_stick x1 → iron_knife
scrap_iron x2 + wooden_stick x1 → hammer   採掘の等級1。岩が開く
scrap_iron x2 + wooden_stick x1 → cleaver  伐採の等級1。木が開く
```

- 新しいアイテムは作らない。`hammer` と `cleaver` は等級1の道具として既にある。
- 足すレシピは `wooden_stick`、`hammer`、`cleaver` の3つ。`iron_knife` の材料を `iron` と `wooden_stick` から、`scrap_iron` と `wooden_stick` に改める。
- `wooden_stick` は武器のグループ `early_melee_weapon` から外す。棒は材料であって、拾える武器ではなくする。

```toml
[[recipes]]
  id = "wooden_stick"
  name = "Wooden Stick"
  [[recipes.inputs]]
    amount = 2
    id = "branch"
```

素材から完成品までの流れが途切れないことを、テストで固定する。レシピの材料のどれもが、道具なしで取れる素材か、作れる物から辿れることを確かめる。

```go
// TestRecipes_序盤の武器と道具は道具なしで取れる素材から作れる は、wooden_sword・iron_knife・hammer・cleaver の材料を
// レシピで遡ると、道具の要らない分解の産出に行き着くことを確かめる
```

## 採用しなかった方法

- **一定の日数を生き延びたらクリア**: 北へ進む理由にならない。北進の軸と「移動する拠点」につながらない。
- **目的地を置かず、どこまで北へ行けたかを記録する**: 終わりが無いと、判断の基準になる締め切りも生まれない。記録はクリアの後に足せる。
- **南から寒さの前線が迫る**: 一度作って、温度と資源の枯渇による自然な前進に置き換えた。季節の冬で締め切りは作れる。
- **新しい石器のアイテムを足す**: `hammer` と `cleaver` が等級1の道具として既にある。アイテムは増やさず、レシピでつなぐ。
- **初期の持ち物に武器を足す**: 職業ごとの差が消え、作る段を踏む理由も無くなる。
- **キューブの部位と変異を先に入れる**: ループが回る前に足すと、また「仕組みはあるが遊びが無い」状態に戻る。部位は、北の障害を越える手段としてループの後に載せる。

## コメント

- ゴールの形は「北の目的地に到達でクリア」で合意済み。
- 主体は人で、キューブは移動する拠点という前提を保つ。キューブは安全をくれない。
- `goalDepthChunks` の30は仮の値。バランス計算で目的地までの日数を見積もり、冬の底より前に着く値へ振る。
- 「合成が機能していない」には、UI の不具合が混ざっている可能性もある。4の作業の初めに、今あるレシピが実際に作れるかを手で確かめる。
