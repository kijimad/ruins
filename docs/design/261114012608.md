# 複数のチャンクにまたがる建物を、部屋の絵の組み合わせで作る

## 背景

区域の建物は、1チャンクに1棟で、どれも 20×20 の絵1枚でできている。設計 doc 261113010103 と 261113205202 の形。参考 codebase: `internal/overworld/urban.go`。

- すべての建物が同じ大きさに見える。研究所の本館のような、何チャンクにもまたがる巨大な建物を置けない。
- スーパーのような広い売り場も、1チャンクの中にしか描けない。
- 1枚の大きな絵で描くと、描く量が大きく、毎回同じ間取りになる。

## 要件

1. 施設ごとに、チャンク数で数えた建物の大きさを変えられる。
2. 何チャンクにもまたがる建物は、チャンク大の部屋の絵の組み合わせで作り、毎回違う間取りになる。研究所の本館は迷路のように部屋が扉で繋がる。
3. スーパーのように、チャンクの境に壁の無い広い空間も作れる。
4. 生成は今と同じく、run の seed とチャンクの座標の純関数のままにする。各チャンクは隣のチャンクを生成せずに自分の中身を決める。

## 設計

### 建物の区画

区域の中を、建物の区画で埋める。区画は w×h チャンクの矩形で、施設を1つ持つ。区画の割り振りは区域の seed の純関数で、チャンクを生成するたびに区域の全体を割り振り直し、自分を含む区画を引く。区域は高々 7×8 チャンクなので軽い。

```cue
#Facility: {
	id!: #EntityID
	// ...今の欄...
	// 建物の大きさの候補。チャンク数で、区画に収まらなければ小さい候補へ落とす。省けば 1×1
	footprints?: [...#FacilityFootprint]
	// 2チャンク以上の建物の中の繋がり。rooms は部屋を扉で繋ぐ迷路、hall はチャンクの境に壁の無い広い空間
	interior?: #FacilityInterior
}

#FacilityFootprint: {
	w!:      int & >=1
	h!:      int & >=1
	weight!: int & >=1
}

#FacilityInterior: "rooms" | "hall"
```

```go
// internal/overworld。区域の中の建物の区画
type buildingLot struct {
	facility string
	anchor   consts.Coord[consts.Chunk] // 区域の中の座標
	w, h     consts.Chunk
	seed     uint64
}

// lotsOf は区域 r を建物の区画で埋める。左上のチャンクから順に、未割り当てのチャンクの地区で施設を引き、
// 施設の大きさの候補を重みで引く。同じ地区で未割り当てのチャンクだけに収まる大きさまで小さくする
func lotsOf(cat zoneCatalog, r districtRegion) []buildingLot
```

- 区画は1つの地区の中に収める。研究所の本館は中ほどの地区の中に建ち、門や閉鎖区画の列にはみ出さない。
- 大きさの候補が区画に収まらないときは、収まるまで辺を縮め、最後は 1×1 にする。

### 区画の中の繋がり

2チャンク以上の区画では、区画の中のチャンクどうしの繋がりを区画の seed から決める。

- `rooms` は区画の中のチャンクを節にした全域木を、seed で順を混ぜた深さ優先で作る。木の辺が扉になり、それ以外の内側の辺は壁になる。迷路になり、どの部屋にも入れる。
- `hall` は内側の辺を全て吹き抜けにする。
- 入口は区画の北の辺の真ん中の列のチャンクに1つ開ける。北の辺は街路に面する。

```go
// edgeKind はチャンクの辺の種類
type edgeKind string

const (
	edgeWall edgeKind = "wall" // 壁
	edgeDoor edgeKind = "door" // 辺の真ん中に扉
	edgeOpen edgeKind = "open" // 辺の全体が吹き抜け
)

// roomEdges は区画の中のチャンク l の、北・東・南・西の辺の種類を返す。区画の seed の純関数
func (b buildingLot) roomEdges(l consts.Coord[consts.Chunk], interior rawschema.FacilityInterior) [4]edgeKind
```

### 部屋の絵

部屋の絵は今の施設の絵と同じ 20×20 で、施設と、4つの辺の種類を書く。

```toml
[[chunk]]
name = "20x20_lab_main_corridor"
facility = "lab_main"
edges = { north = "door", east = "wall", south = "door", west = "wall" }
weight = 100
palettes = ["lab"]
map = """
...
"""
```

- 扉の辺は、辺の真ん中の2マスを扉にして描く。回転と反転で扉の位置が動かないように真ん中に置く。2マスの扉は隣が扉になるので、扉の向きを決めるときは隣の扉も壁と同じく数える。吹き抜けの辺は辺の全体を床にして描く。
- チャンクは、要る辺の種類に合う絵を、回転と反転を含めて重みで選ぶ。絵1枚が回転と反転で最大8通りの辺に使える。
- 迷路の部屋の形は、行き止まり・角・直線・T字・十字の5通りの辺の組で全ての組を覆う。
- 絵の中は今の部品の入れ子で変化を付ける。

### 隣のチャンクとの間の帯

チャンクは北と西の辺に幅4の帯を持つ。区画の外周では今と同じく街路にする。区画の内側では、隣の部屋との繋ぎとして描く。

- 壁の辺の帯は、壁と、その両側の屋内の床で埋める。
- 扉の辺の帯は、2つの部屋の扉を結ぶ幅2の廊下にし、両脇を壁にする。
- 吹き抜けの辺の帯は、全体を床にする。
- 北と西の帯が交わる左上の 4×4 は、周りの辺に合わせて壁か床にする。

## 採用しなかった方法

- **建物を1枚の大きな絵で描く。** 描く量が大きく、毎回同じ間取りになる。
- **チャンクより小さい部屋を辿って建物を組む。** 変化は細かいが、部屋がチャンクの境をまたぐので建物全体の配置を区画の seed から決めて各チャンクが切り出す作りになり、重い。
- **部屋の絵を 24×24 にして帯を絵に含める。** 区画の外周のチャンクだけ街路と重なるので、外周と内側で絵の大きさが変わる。20×20 の絵と帯の描き分けにすれば、今の施設の絵と同じ大きさで描ける。
- **出入口の位置を絵ごとに自由にする。** 隣の部屋と出入口の位置を合わせる約束が要る。辺の真ん中に固定すれば、帯の廊下が真っ直ぐに繋がる。

## コメント

- 部屋の絵を5通りの辺の組で揃えるのが最初の作業量になる。研究所の本館で揃え、スーパーは後で足す。
- 1×1 の施設は今の施設の絵のまま使う。辺を書かない絵は、北の辺に入口がある1棟の建物として扱う。
