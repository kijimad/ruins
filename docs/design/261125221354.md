# 1つの土地に数日とどまり、尽きたら家ごと移る

## 背景

提供したい体験の核は「廃墟を漁ってキューブを育て、土地の資源が尽きたら家ごと次の土地へ移る」である。今のゲームでは、1つの土地にしばらくとどまる遊びが生まれていない。

今の作りを調べると、とどまる理由も移る手間もほぼ無い。

| 項目 | 今の状態 |
|---|---|
| 移る手間 | キューブを畳む・広げるは、メニューの1回の選択で、手番も燃料も使わない。設置した設備も同じ並びのまま運ばれる |
| 燃料 | ついてくる1歩ごとに減るだけ。満タンの空のキューブで約600歩、20チャンク以上進める |
| とどまる理由 | 焚き火の暖と寝床だけ。キューブは暖を出さず、暖房の設備も無い。工作台には作る側の働きが無い |
| 世界の形 | 横9チャンク・縦9チャンクの帯で、北の端に近づくと北へずれ、南の行は捨てられて戻らない |

土地が何日もつかを測った。開始の行の周り 7×9 チャンクを5つの seed で生成し、拾える食べ物と燃料を数えた。1日の消費は、食べ物が満腹1回の 500、燃料が地面の焚き火を1日もたせる熱量 3000 とした。

| チャンクの種類 | 割合 | 食べ物 1チャンク平均 | 燃料 1チャンク平均 |
|---|---|---|---|
| 荒れ地 | 75% | 0日分 | 0日分 |
| 道 | 14% | 0日分 | 0日分 |
| 集落 | 3% | 0.6日分 | 0.05日分 |
| 市街地 | 4% | 0.5日分 | 0.4日分 |

拠点の周り 3×3 チャンクを1つの土地としたとき、食べ物と燃料の少ない方で決まる日数は、中央値で0日、上位10%でも0.2日だった。敵の落とし物に食べ物は無く、置物には材質と重さが無いので壊しても燃料にならない。

問題は「移るのが簡単すぎる」ことよりも、どの土地もとどまる理由になる物を持っていないことにある。

## 要件

- 1つの土地に、ゲーム内で数日とどまる
- とどまる間にやることがある。加工、探索、罠や壁などの拠点の強化
- 遊びの手触りは、移りながら生き延びる緊張感にする
- 拠点を強化しても、ずっと住めるようにはしない。強化は時間を買う物で、ずっとの安全は買えない
- 厳しさはプレイヤーの強さでなく、場所と時で決まる
- とどまることを、ただ待つだけで得をする遊びにしない

## 設計

### 時計: 毎日の消費と、土地の限りある供給

とどまれる日数は「その土地で手に入る量 ÷ 1日の消費」で決まる。生きるのに毎日要る食べ物と燃料が尽きると、とどまれなくなり、移る。尽きても困らない物が尽きても圧にならないので、時計は食べ物と燃料で作る。

この時計の上で、加工はとどまる日数を延ばし、探索は供給を見つけて延ばし、拠点の強化はその日数を安全に過ごす手段になる。いずれ尽きるので、強化してもずっと住めることにはならない。

目標は、普通の土地が数日もつこと。量は測って合わせる。

### 土地の供給: 狩りと罠、薪

| 出どころ | 中身 | 尽き方 |
|---|---|---|
| 狩りと罠 | 土地の獣を狩る、または罠を仕掛けて待つと、肉が得られる | その土地の獣は数に限りがあり、狩るほど減る |
| 薪 | 木や家具を道具で壊して薪にする | 周りの木と家具の数に限りがある |

拾える物の量を増やすだけでは、拾って移るのが速くなるだけで、とどまる手触りにならない。時間をかけて得る出どころを足す。

### 拠点の強化: 壁と罠

家の周りに壁と罠を置き、とどまる間を安全に過ごす。家を畳んで移るときは置いていく。壁と罠の材料は安く、手早く置けるようにし、移るたびに作り直すのが面倒なだけにならないようにする。

### 燃料を締める

土地の供給が整ったうえで、移る燃料を締め、移ることを重い決断にする。量は時計と合わせて測って決める。

### 世界の形: 帯を家に合わせる

帯がずれるきっかけを、プレイヤーの位置でなく家の位置にする。家を置いている間は周りの土地が消えず、どの方向にも探索できる。家を北へ動かしたときだけ、帯が北へずれて南の土地が消える。あわせて帯の横幅を広げ、拠点の周りを数日かけて探索できるようにする。

```go
// 帯を北へずらすかを、プレイヤーでなく家の帯ローカルの行で判断する
if dr.band.ShouldShiftNorth(cubeLocalY) {
	if err := dr.band.ShiftNorth(world, dr.gen); err != nil {
		return err
	}
}
```

### 後で足す味付け

次は、上の仕組みで遊んでみて、まだ足りなければ足す。

- 暖機運転: 家を広げた直後は設備が冷えていて能率が低く、動かしているうちに今の能率まで戻る。今の能率より上には上げない。加工の設備ができてから考える
- 気配: とどまるほど周りの敵が気づいて寄ってくる。発つ時を急かす圧が足りなければ足す

## 採用しなかった方法

- 燃料だけを締める。移るのが面倒になるだけで、とどまる理由は生まれない
- 畳む・広げるに手番をかける。足止めの手間が増えるだけで、選ぶ所が生まれない
- 家の温まり。家が住むほど暖まるという理由が不自然だった
- 土地勘や段取りで能率が上がる。とどまるほど楽になり、厳しさが削れる
- 設備の能率をとどまるほど上乗せする。ヌルくなる。暖機運転は、上限を今の能率にする形でだけ後の候補に残す
- 尽きることだけを圧にする。漁り尽くした土地でも、固めた家に安全に居座れて、緊張にならない。毎日の消費と組み合わせる
- 拾える物を増やすだけ。拾って移るのが速くなるだけ
- 土地を区切り、間を俯瞰図の旅にする。とどまる・移るのリズムは一番はっきりするが、地続きの世界を作り直す大きな変更になる。帯を家に合わせて足りなければ考える
- どの方向にも続く地続きの世界にする。漁った跡を土地ごとに保存する仕組みが要る

## コメント

- 測った数字は、開始の行の近くだけの値で、北の奥では違うかもしれない。測るのに使ったテストはコミットしていない。土地が何日もつかは、`internal/balance` の指標として残すのがよい
- 1つの土地に何日いてほしいかは数日とした。数字はまだ決めていない
- 他のゲームの記憶として、漁れる物が有限で尽きたら移る、手をかけた物が時間をかけて実る、という形がとどまる理由として働いている。確かめてはいない
