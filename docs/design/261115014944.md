# マクロ地図の荒れ地を雪の割合で白くする

## 背景

地上の地面には、その日の平均気温から導いた量の雪を重ねて描いている。設計は `docs/design/261114172029.md`。一方、マクロ地図は季節や緯度に関係なく同じ色で、北の寒さや季節の雪の境目が読めない。

マクロ地図は1チャンクを1セルで描き、セルを記号の色で塗る。描画モデル `BuildMacroView` は世界の状態を受け取らない純粋な関数で、全画面の俯瞰図と HUD の小地図が共有する。参考 codebase: `internal/overworld/macro_view.go:70`、`internal/widgets/hud/map_grid.go:27`。

## 要件

1. 雪の割合は、地面の雪と同じ式から導く。マクロ地図だけ別の基準にしない。
2. 白くするのは地面を表すセルだけにする。施設のセルは色で種類を見分けるので、白くすると読めなくなる。
3. どの記号のセルを白くするかは、記号の行の欄で示す。
4. `BuildMacroView` は世界の状態を受け取らない純粋な関数のまま保つ。

## 設計

### 絶対チャンク行の雪の割合

マクロ地図の行は絶対チャンク座標で、帯の外も含む。帯ローカル座標を受ける `SnowFractionAt` は使えないので、湧き位置からの奥行きで気温を引く関数を足す。

```go
// SnowFractionAtChunkRow は絶対チャンク行 row で、雪に覆われる地面のマスの割合を返す
func SnowFractionAtChunkRow(world w.World, row consts.Chunk) float64
```

季節と緯度の気温は、奥行きから求める関数に一本化し、帯ローカル座標の `ClimateTemperatureAt` もそれを通す。

### 記号の行が雪で白くなるかを持つ

```cue
#MapGlyph: {
	// ...
	// 雪が積もると、この記号のセルを雪の割合だけ白へ寄せる
	snowy?: bool
}
```

荒れ地の記号 `field` に付ける。

### 描画モデルがセルの雪の割合を持つ

```go
type MacroCell struct {
	// ...
	Snow float64 // セルを白へ寄せる割合。0 なら記号の色のまま
}

func BuildMacroView(..., snowAt func(row consts.Chunk) float64) MacroView
```

- 雪の割合は呼ぶ側が `snowAt` で渡す。`BuildMacroView` は世界の状態を受け取らない。
- `snowy` の記号のセルだけに `snowAt` の値を入れる。
- `DrawMapGrid` は、セルの色を雪の色へ `Snow` の割合で寄せて塗る。

## 採用しなかった方法

- **全てのセルを白へ寄せる**: 施設の種類を色で見分けられなくなる。
- **荒れ地かどうかを記号やチャンクの種類の値で比べる**: 列挙の値の直接比較は lint で禁じている。白くなる記号を足すたびにコードを直すことにもなる。
- **`BuildMacroView` に world を渡す**: 描画モデルが世界の状態に依存し、テストで world を組む必要が出る。
- **調べる画面に雪の量を出す**: 雪は3D描画で見えているので、文字で重ねる価値が小さい。
