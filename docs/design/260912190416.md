# 北進サバイバル。無限軸を北へ反転し寒冷勾配で北を目指させる

## 背景

現状は worldstream が東西へ無限ストリーミング・南北を rows で有界とする帯で、進行軸は東。東進に意味づけが無く、終点も勝利条件も無い。プレイヤーは何を目指すのか分からない。

そこで進行軸を北へ回し、「北ほど寒い」という直感的な難易度勾配と「北を目指す」という目的の土台を作る。筋書きは、キューブ故障で極寒惑星に墜落した宇宙トラベラーが北を目指して生き延びるというもの。北の深部で施設を得てキューブを修理し脱出する到達点は、この土台の上に別 doc で載せる。

## 要件

1. worldstream の無限ストリーミング軸を東から北へ物理反転する。北は画面の上すなわち -Y。南北が無限、東西が有界になる。
2. 北へ進んだ距離が増えるほど周囲気温が下がる緯度勾配を気温計算に加える。
3. オープニングの進路説明を「東」から「北」へ更新する。
4. 北への奥行きを HUD と方位表示で示す。

要件1は一度「物理軸は東のまま方向は提示だけで北と示す」低リスク案を採ったが、上キーで北へ進む直感を優先して物理反転を実施した。生成系は X-無限前提だったので、`Placement` のリージョン割りを Y へ回し、道の結線も Y リージョン間へ直した。

## 設計

### 進行軸の物理反転

`internal/worldstream/band.go` の無限軸を北へ回す。`eastIndex`→`northIndex`、東端生成・西端破棄・リベースを北端生成・南端破棄・+chunkH リベースへ置き換える。北は -Y なので東進コードの符号鏡像になる。帯ローカル座標は画面と一致させ、localY=0 が北端、絶対 Y は南向きに増加し北へ進むほど負へ伸びる。

```go
type Band struct {
	chunkW, chunkH consts.Tile
	cols, rows     consts.Chunk // 有界=東西(cols)、無限=南北(rows を北へ流す)
	northIndex     consts.Chunk // 北進したチャンク数。北へ進むほど増える
}
// ShouldShiftNorth(localY) = localY < centerSlot*chunkH  すなわち中央行の北へ出たら発火
// ShiftNorth: 南端行破棄 → 全体+chunkH リベース → northIndex++ → 北端行(絶対チャンクY=-northIndex)生成
```

生成系は「X=無限・Y=有界」を前提にしていたので、`Placement` のリージョン割りを Y へ、有界カウントを `rows`→`cols` へ回す。道の結線 `crossingRoads`・`buildRoadOverlay` も Y リージョン間へ直す。マクロ地図 `MacroRange` に `OriginY` を足し縦帯として描く。絶対 Y は `SeamlessBand.LocalToAbsY` = `localY - NorthIndex*chunkH`。

### 寒冷の緯度勾配と北への奥行き表示

`query.AmbientTemperatureAt` へ奥行き距離ベースの項を足す。奥地ほど寒くなる分を世界温度に折り込むので、屋内は `shelteredWorldTemp` で緩和される。奥行きは `query.NorthDepthChunks` を単一の出どころにし、気温勾配と HUD 右下の `North N` 表示が同じ距離を共有する。起点は初期帯の中央行で、開始地点を穏やかに保つ。

```go
const (
	latitudeColdPerChunk = 1  // 1チャンク北へ進むごとに下がる℃
	latitudeColdMax      = 40 // 下げ幅の上限
)
func NorthDepthChunks(world w.World, y consts.Tile) int // 中央行起点の北奥行き。負の絶対Yは floorDivInt で連続
func latitudeColdForDepth(chunksDeep int) int           // 単調増加し latitudeColdMax で頭打ち
```

## 採用しなかった方法

- **提示だけで北と示す低リスク案**。物理軸は東のまま、方位表示と物語だけで北と呼ぶ。一度採ったが、上キーで北へ進む直感を優先して物理反転へ切り替えた。
- **有限の緯度世界**。南=温暖・開始 → 北=北極点=終点の有限マップ。北極点を固定終点にできるが、無限ストリーミングの帯機構を丸ごと捨てる最大の改修になるため不採用。北へ無限に伸ばす本案でも、北の深部を到達点にできる。

## コメント

- 寒冷勾配の急さ `latitudeColdPerChunk` と下限 `latitudeColdMax` は実プレイで詰める暫定値。
- 軸反転は座標系の広範な追随を伴うので、VRT golden と worldstream の既存テストで挙動を固定した。scatter golden の縦に走る道が生成系の再方位付けの証拠。
- 北の深部での施設出現・キューブ修理・修理完了でのクリアは、この土台の上に別 doc/タスクで載せる。
