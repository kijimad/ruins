# 原野のランドマークを施設の絵で描く

## 背景

原野のランドマークは、廃屋・農家・祠・野営地の4種で、raw の `landmarks` の行に描き方を書いている。参考 codebase: `internal/overworld/landmark.go`。

- 描き方を列挙 `drawer` で切り替え、`hut` は壁と床と扉の小屋をコードで組み、`open` は家具を相対座標で並べる。
- 描き方ごとに要る欄が違うので、スキーマに「`drawer` が `hut` のときだけ小屋の欄が必須」という条件付きの欄が要る。
- 壁・床・扉・家具を置く仕事は、施設の絵の仕組みがもう持っている。小屋を組むコードは、屋内外のタイル、絵の変種、回転と反転、収納の戦利品表を持たず、施設の絵に入った改善が届かない。

## 要件

1. ランドマークを施設の絵とパレットで描く。描き方の列挙と小屋の欄をなくす。
2. raw のランドマークの行は、どの施設をどの重みで原野に置くかだけを書く。
3. 廃屋・祠・野営地の見た目と中身を保つ。地図の記号も変えない。
4. 農家は、隣のチャンクまで広がる庭を持つ農場の区域にする。

## 設計

ランドマークの4種を施設にする。施設の行と絵とパレットで描き、ランドマークの行は施設を指すだけにする。

```cue
// 変更前
#Landmark: {
	id!:     #EntityID
	weight!: int32 & >=1
	drawer!: #DrawerKey
	hutW!:   int32
	hutH!:   int32
	props!: [...#PropSpot]
	hutFloor?: #EntityID
	hutWall?:  #EntityID
	if drawer == "hut" { ... }
}

// 変更後。id は施設の id で、地図の記号もこの id で引く
#Landmark: {
	id!:     #EntityID
	id_ref:  _facilityIDs[id] @rawgen(-)
	weight!: int32 & >=1
}
```

```toml
[[landmarks]]
  id = "abandoned_hut"
  weight = 30
```

- 施設の絵は区画の大きさを名前で持つので、原野の小さな建物を `8x7_abandoned_hut` のように描く。建物の外周に土の縁を1マス付け、扉の外へ出られるようにする。
- 施設の絵を置く `spawnFacility` は、絵がチャンクに収まることを確かめる。今は区画の右下までちょうど埋まることを求めているので、原野の小さな絵が置けない。
- ランドマークは、原点をチャンクの内側に絵が収まる範囲から引き、施設の絵を回転と反転を含めて置く。
- ランドマークの施設は、どの地区にも出ない。町の施設の抽選には混ざらない。

### 農場の区域

1チャンクに収まる建物はランドマーク、チャンクをまたいで広がる敷地は区域で描く。農家は廃屋と見分けがつかないので、母屋と納屋と畑と家畜の囲いを持つ区域にする。

```toml
[[districts]]
  id = "farm"
  pattern = "rows"
  fence = true
  street = "dirt"
  landmark = "farmhouse"
  [[districts.layers]]
    zones = ["farm_field"]
  [[districts.layers]]
    rows = 1
    zones = ["farm_yard"]
```

- 区域の行は町より後ろに置き、町に重なったら出さない。
- 目玉の施設の母屋は大きさの候補を持たないので、区画の割り振りと同じく 1×1 として置く。
- 作物の家具の絵はダミーで足す。

### 地図の凡例

全画面の地図の凡例は全ての記号を並べていて、施設を足すと枠からあふれて切れていた。表示範囲の開放済みのチャンクに出ている記号だけを並べる。

## 採用しなかった方法

- **描き方ごとに表を分ける。** 条件付きの欄は消えるが、小屋を組むコードが施設の絵と二重に残る。
- **小屋の欄を1つのオブジェクトにまとめ、条件付きで必須にする。** 欄はまとまるが、条件付きの欄が残る。
- **ランドマークを1チャンクの区域にする。** 区域は街路と区画を持つので、原野の小さな建物には大きすぎる。

## コメント

- 祠と野営地は戦利品が無かったが、施設の建物は戦利品を出すという今の約束に合わせ、祠に供え物の骨董品、野営地に食料を床に置く
- 施設の絵は回転と反転を含めて置くので、同じ seed でもランドマークの向きと位置が今と変わる

- 施設の絵を置く仕組みが、町と区域と原野の3か所で共通になる。
