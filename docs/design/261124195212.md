# 湖の区域

## 背景

地上に川・湖・沼のような水面が無い。最初は絶対タイル座標のノイズで湖と沼を荒れ地へ撒いたが、人の手が入った土地に水たまりが散らばるのは現実的でなく、飾りにしかならなかった。

水面は、研究所や発電所と同じ区域として作る。地図の上で1つのエリアに見える大きな湖があり、その周りに湖のための施設が建ち、桟橋が湖へ伸びる。湖が取水場や釣り場やキャンプ場の理由になり、北へ進む道中で寄り道する先になる。

水面のタイルは別に用意する。浅瀬 `water_shallow` と深い水 `water_deep` で、どちらも通れ、移動コストは浅瀬 100、深い水 300 を標準の移動に上乗せする。上に立つと水中、隣に立つと水辺の冷えを受ける。

## 要件

- 地図の上で1つのエリアとして見える大きな湖が、研究所や発電所と同じ間隔で北への道中に現れる
- 湖の周りに、湖のための施設が建つ。釣り小屋・広場・キャンプ場・取水場
- 湖の岸から桟橋が湖へ伸びる
- 湖の中を街路や道が横切らない。区域の門から入り、岸を回って施設へ行ける
- 湖の岸の線は、チャンクの格子に沿った直線にならない
- 俯瞰図で湖とわかる記号が出る
- 新しい種類は raw の行と絵とパレットで足す。コードは部品だけにする

## 設計

今の区域の仕組みに、2つの部品を足す。水で満たす層と、湖へ向く施設である。湖の区域はこの2つと raw の行で組む。

### 今の区域の仕組み

区域は数チャンク四方の長方形で、`spacing` チャンクのリージョンごとに1つ当選する。地区の並べ方 `pattern` が `rings` なら外の層と内の層の2層になる。層ごとの `zones` がそのチャンクに建てる施設の組を決め、施設は施設の絵を1枚ずつ置く。区域の全てのチャンクは北と西の辺に幅4の街路を持ち、施設の絵は残りの 20x20 に置く。主の施設 `landmark` はその層のチャンクの外接矩形の中央に置く。道は区域に入らず、北と南の門の前までつなぐ。

### 層の構成

`rings` の2層で組む。湖畔は施設の並ぶ街でなく、自然の岸に施設が点々と建つ土地にする。

| 層 | 中身 |
|---|---|
| 内の層 | 湖。楕円にノイズを足した輪郭の水面を描き、輪郭の外は自然の地面に残す。街路も施設も置かない |
| 外の層 | 岸。施設を建てるのは数チャンクだけで、残りは木・草・岩を撒いた自然の地面にする |

区域の全てのチャンクに街路と施設を置く今の決まりのままでは、湖が施設の輪に四角く囲まれ、公園の池のように見える。湖らしく見せるため、湖の輪郭をチャンクの格子から外し、岸の大半を自然のまま残す。

```
. . . . . . .      . は自然の岸。木・草・岩
. . ~ ~ ~ . .      ~ は湖。輪郭は楕円とノイズで出入りする
. ~ ~ ~ ~ ~ .
. ~ ~ ~ ~ ~ .
. . ~ ~ ~ . .
. . C P . . .      C P は施設。道の来る南の辺の中央に近いチャンクから数か所だけ
      |            | は道。湖の手前まで来る
```

### データ

層に、水で満たす印を足す。

```go
// 変更前
type DistrictLayer struct {

type DistrictLayer struct {

// 区域の街路は省けるようにする
type District struct {
	// ...今の欄...

	// 街路のタイル。省くと街路の格子を引かない
	Street *EntityID `json:"street,omitempty"`
}

// DistrictWater は水で満たす層の水面
type DistrictWater struct {
	// 深い水・浅瀬・浜のタイル。タイルの名前を Go に書かず raw の行で選ぶ
	Deep    EntityID `json:"deep"`
	Shallow EntityID `json:"shallow"`
	Beach   EntityID `json:"beach"`
	// 俯瞰図に出す記号の行
	Glyph EntityID `json:"glyph"`
	// 桟橋の板のタイルと、浅瀬を越えて深い水へ伸びる長さ
	Pier       EntityID `json:"pier"`
	PierLength int      `json:"pierLength"`
	// 浜の幅。水で満たさない隣へ向く辺にだけ付ける。街路と水の間を必ずこの幅だけ空けるので揺らさない。タイル数
	BeachWidth int `json:"beachWidth"`
	// 浜の内側の浅瀬の幅。タイル数
	ShallowWidth int `json:"shallowWidth"`
	// 湖の輪郭を楕円から出入りさせる量。タイル数
	ShoreWobble int `json:"shoreWobble"`
	// 輪郭の出入りの格子の間隔。大きいほどゆるい入り江になる。タイル数
	ShoreCell int `json:"shoreCell"`
}
```

施設には欄を足さない。湖に接するチャンクに建つ施設は、どれも湖へ向ける。区画が湖へ向くかと回す回数は、区画を組むときに導く。

```go
type buildingLot struct {
	// ...今の欄...

	// facesWater なら施設の絵を左回りに turns 回だけ回し、北の辺を接する湖へ向ける
	facesWater bool
	turns      int
}
```

### 湖の描き方

湖は内の層のチャンクに、施設の絵を置かず手続きで描く。輪郭は、内の層のチャンクを合わせた長方形に収まる楕円を基にし、絶対タイル座標の値ノイズで出入りさせる。

- 各マスについて、楕円の内側へどれだけ入っているかをマス数で測り、値ノイズで `ShoreWobble` マスだけ増減させる。この値を岸からの深さと呼ぶ
- 岸からの深さが0未満のマスは陸で、下地の土を残す。0から `BeachWidth` までを浜、そこから `ShallowWidth` までを浅瀬、その内側を深い水にする
- 楕円は内の層の長方形から `ShoreWobble` と `BeachWidth` の分だけ内側に取り、湖が外の層のチャンクへはみ出さないようにする
- 楕円とノイズは絶対タイル座標の純関数で、区域の中のどのチャンクも同じ種を使う。チャンクの境目で輪郭が途切れず、再訪しても同じ湖になる
- タイルはオートタイルしないものを置くので、行の仕様どおり添字を付けずに置く
- 街路の帯を引かず、敵も湧かせない。輪郭の外の陸は、層の `Scatter` の散布で木や草を撒く
- 施設を建てたチャンクの真ん中から、接する湖の側へ幅2の桟橋を伸ばす。浜から板を張り、浅瀬を越えて `PierLength` だけ深い水へ入った所で止める。湖の輪郭が出入りしても、輪郭から測るので必ず水に届く

### 大きさと優先順

区域の大きさは 7x7 にし、内の層は 5x5 になる。`rings` は中心の層を短い辺から決めるので、正方形でないと外の層が長い辺の側で2チャンクの厚さになる。正方形だけにする。

区域は raw の行の順が優先で、先の種類の区域と重なるか隙間なく接すると、後の種類は丸ごと出ない。湖の区域は発電所の後に置く。地上の帯は15列で、30 の seed で 450 行ずつ数えると、湖はおよそ230行に1度出る。研究所・軍の基地・発電所の出方は変わらず、町と農場がそれぞれ16%ほど減る。

### 湖へ向く施設

外の層のチャンクのうち、上下左右のどれかに水の層のチャンクが接するものを岸のチャンクと呼ぶ。湖の輪郭は内の層の中に収まるので、岸のチャンクと水際の間には自然の地面が挟まる。

- 岸のチャンクに建つ施設は、どれも湖へ向ける。施設を選ぶときに湖へ向く施設を優先することはしない
- 施設の絵は、北の辺を水の側にした1枚だけを描く。描画のときに絵を回し、北を隣の水の層の向きへ向ける。今の施設の絵は向きを乱数で決めているが、岸のチャンクだけは向きを決めて回し、左右の反転だけを乱数で選ぶ
- 桟橋の板は屋根の無い屋外のタイル `pier_plank` にする。床の板 `plank_*` は屋内なので、桟橋に立つと寒さをしのげてしまう
- 桟橋は施設の絵の端から水の側へ伸ばし、水際までの距離は湖の輪郭から測って長さを決める。湖の輪郭が出入りするので、施設の絵だけでは水際に届かない。伸ばし方は段 2 で決める
- 水の層が2方向に接する岸のチャンクは、どちらか一方へ向ける。南と北を西と東より先にする

### 街路と道と施設を建てるチャンク

- 湖の区域は街路のタイルを省き、街路の格子を引かない
- 外の層で施設を建てるのは `Lots` チャンクだけにする。道の来る南の辺の中央に近い順に選び、同じ近さなら区域の seed で並べる。湖畔の施設は道から寄りやすい側に集まる
- 施設を建てないチャンクは、施設の絵を置かず、層の `Scatter` の散布で木・草・岩を撒く。敵は湧かせない
- 施設を建てるチャンクは今どおり施設の絵を置き、`streetEnemies` の敵を湧かせる
- 道は今どおり北と南の門の前までつなぐ。門の列は区画から引いているので、門の位置のチャンクが自然の地面なら、真ん中の列をそのまま門にする
- 塀は巡らせない
- 俯瞰図で、施設の無いチャンクは荒れ地の記号を出す

### 主の施設

取水場を主の施設にする。今の主の施設は層のチャンクの外接矩形の中央に置くので、外の層では中央が湖になって置けない。真ん中に建てられなければ、同じ大きさで真ん中に一番近い建てられる区画に置く。湖の区域では施設を建てるチャンクが南の辺の中央に集まるので、主の施設は南の門の側になり、道から最初に見える。

取水場は南の辺の中央の 3x1 を占め、発電所のタービン建屋と同じく吹き抜けの部屋の絵で組む。施設を建てるチャンクは4つにし、残る1つに湖畔の施設が建つ。部屋の絵は回さずに置くが、南の辺の区画は必ず北が湖なので、入口の扉は湖を向く。桟橋は区画ごとに1本で、区画の真ん中のチャンクに置いた絵の真ん中から伸ばす。取水場では入口の扉の前から湖へ出る取水口になる。

### 俯瞰図

水で満たす層のチャンクは、湖の記号を出す。今の記号は施設の id で引くので、水の層には施設が無い。水面の欄 `glyph` で記号の行を指し、CUE の参照で記号の行が無いことを落とす。

### 施設

| 施設 | 層 | 中身 |
|---|---|---|
| 取水場 `water_intake` | 外 | 主の施設。3x1 の吹き抜けに揚水の機械と制御盤が並び、北の扉から取水口の桟橋が湖へ出る |
| 釣り小屋 `fishing_hut` | 外 | 小さな小屋。寝台と保存食 |
| 広場 `lakeside_plaza` | 外 | 舗装の広場と長椅子 |
| キャンプ場 `campsite` | 外 | 焚き火の跡とテント |

桟橋は施設にせず、湖を描くときに施設を建てたチャンクから手続きで伸ばす。

### 進め方

3段に分ける。各段は単独で地図に出せる。

1. 湖と岸だけの区域。輪郭が自然に出入りする湖と、自然の岸に広場とキャンプ場を数か所だけ置く
2. 湖へ向く施設。回す向きの決め方を作り、釣り小屋を足す。桟橋は段 1 で湖を描くときに手続きで伸ばす。1棟の絵は区画の入口のチャンクが接する湖へ向けて回すので、湖の区域の地区に建つ施設は主の施設のほかは 1x1 に限り、raw の検証で落とす
3. 取水場を主の施設にし、外の層の南の辺に置く

## 採用しなかった方法

| 案 | 理由 |
|---|---|
| 荒れ地にノイズで湖と沼を撒く | 人の手が入った土地に水たまりが散らばるのは現実的でなく、飾りにしかならない。湖を目当てに建つ施設も置けない |
| 湖のチャンクも施設の絵で描く | 隣が湖か岸かで縁の浅瀬の有無が変わり、組み合わせの数だけ絵が要る。手続きで描けば辺ごとに決められる |
| 新しい並べ方 `pattern = "lake"` を足す | 内の層と外の層の2層は `rings` と同じで、違うのは層の中身だけである。層に印を足せば並べ方を増やさずに済む |
| 湖を区域でなく原野の点在ランドマークにする | ランドマークは1チャンクの地物で、地図の上で1つのエリアに見える大きさにならない。周りに施設を建てる層も持たない |
| 道を湖の中に通し、橋で渡る | 区域の中を道が通らない今の決まりから外れる。湖を回り込む岸の街路で足りる |
| 湖を地図全体のノイズのしきい値で決め、つながった範囲を塗り、小さいものを捨てる | 湖の大きさと位置が道の計画や区域の間隔と無関係に決まり、区域や集落と重なる。区域として抽選すれば、他の区域との間隔と道からの入口が今の仕組みのまま保てる |
| 岸の線を、辺を押し込んだ線分の中点を乱数でずらして分割して作る | チャンクごとの乱数で描くと、隣のチャンクとの境目で岸の線が食い違う。絶対タイル座標の値ノイズなら境目で連続する |
| 湖を内の層のチャンクいっぱいに塗り、外の層の全てのチャンクに街路と施設を置く | 段 1 の初版の形。湖が真四角になり、施設の輪に完全に囲まれて公園の池のように見えた |
| 湖を区域でなく、独立した地物にする | 区域の抽選・優先順・俯瞰図・エリア名を作り直すことになる。区域のまま、施設を建てるチャンクの数と街路を省ける欄を足せば足りる |
| 施設に湖へ向く印 `facingWater` を足し、岸のチャンクでその施設を優先して選ぶ | 施設を建てるのは道に近い岸のチャンクだけで、どれも湖に接する。優先して選ぶ仕組みが働く場面が無い。広場やキャンプ場も湖へ向けて困らない |
| 川も一緒に作る | 帯をまたいで1本につながる曲線の経路と、道と交わる所の橋が要る。湖の区域とは別の段で、湖へ流れ込む川として足す |

## コメント

水域の生成は Cataclysm: Dark Days Ahead を参考にした。岸の向きを隣から導くこと、水と陸の間に浜を挟み角を丸めること、先に岸を描いてから施設の絵を重ねることを借りた。
https://github.com/CleverRaven/Cataclysm-DDA/blob/344bfc4ecd31917628363492a0485f0113de0a15/src/mapgen_functions.cpp

決めることを挙げる。

- 区域の大きさと間隔。7x7 で、優先順は発電所の後に決めた
- 湖の中の島や、凍った湖面を渡れる冬の扱い
- 釣りの行為。釣り小屋を置くなら釣りを遊びとして足すか、置物と戦利品だけにするか
- 湖の敵。水辺の生き物を湧かせるか
- 敵の AI と経路探索は移動コスト `PassCost` を見ず、通れるかだけで道を選ぶ。敵は深い水へも避けずに入り、1歩に移動コストを払う。敵にも水を避けさせるか
- 深い水の1歩は標準の移動と合わせて AP を 400 使う。AP の最大値と比べて何ターン止まるかを確かめ、移動コストを調整する

注意すること。

- 移動のたびに移動先の移動コストを数える `getPassCostAt` は、`PassCost` を持つ実体を全て走査する。今は移動コストを持つ置物とタイルが少ないが、湖の内の層が 3x3 チャンクならおよそ5000枚の水面のタイルが移動コストを持ち、1歩ごとの走査が重くなる。ベンチで確かめる前から、座標から引く索引に載せるか、タイルの分は行から引く形を前提にする
