# 進行後半の緩化。想定装備トラックと敵の絶対ダメージ強化で緊張を回復する

## 背景

決定論的バランス導出フレームの進行カーブ `balance/progression.go` が、静的下限すなわちスキル0の最悪ケースと、
想定攻撃頻度から育った想定プレイヤーを同じ日軸で並べたところ、後半の緩化が明確に出た。

- 廃墟 day20 の死亡確率は、床が 25% なのに想定プレイヤーは 0%。
- 決着ターンも想定は day1 の 3.5 から day20 の 2.4 へ短くなる。進むほど楽になっている。

原因は成長が難易度を上回ること。素手スキル Lv30 の熟練度倍率は 2.5倍で、想定プレイヤーは敵が反撃する前に
倒す。danger8 プールの per-enemy 計測では、床で 0〜85% と幅のある全ての敵が、想定Lv30には一律 0% だった。

## 要件

- 普通に育ったプレイヤーが後半にも一定の緊張を感じる。
- 静的下限が理不尽な即死地獄にならない。床は「未成長なら厳しい」に留める。
- スキル成長の手応え、すなわち `balance/skilldepth.go` の実効ティアを大きく損なわない。

## 設計

方向A(敵強化)と方向B(スキル倍率を寝かせる)を計測で検証した。いずれも単独では要件を満たさない。

### 方向A。敵ステータス強化 — 効果限定的

`balance/markov.go` の per-enemy 死亡寄与で確認。danger8 の最強敵 veteran_husk は床 85% でも想定は 0%。
想定を脅かすには敵を床が即死する水準まで上げるしかなく、床の survivability 要件と両立しない。

Aが正当に効くのは「後半に居座る無償勝利雑魚の排除」だけ。rat・bat 等 HP40台が danger8 でも床0%で後半を
薄めていたので、ruins_area の maxDanger を 8→5 に絞った。これで後半の床が締まり day17 の目標帯外れは解消したが、
想定側の 0% は動かない。

### 方向B。熟練度ダメージ係数 coeffWeaponDamage を下げる — 費用対効果が悪い

`components/proficiency.go` の `coeffWeaponDamage`(Lv1あたり+%)を一時的に下げて計測した。

| coeff | Lv30倍率 | 想定 day20 死亡 | 素手スキル 実効/死 ティア |
|---|---|---|---|
| 5(現状) | 2.50倍 | 0.0% | 95 / 5 |
| 3 | 1.90倍 | 0.4% | 90 / 10 |
| 2 | 1.60倍 | 1.8% | 84 / 16 |

36%のグローバル火力ナーフで得るのは +1.8% の死亡確率だけ。代償に手応え(死んだティア)が3倍に悪化する。
出荷しない。

### 根本原因

床と想定の差が埋まらないのは、プレイヤーの生存が撃破速度でなく被弾耐性で決まるのに、進行で伸びるのが
攻撃側(スキル火力)ばかりだから。撃破速度を左右するA・Bを動かしても生存判定はほとんど変わらない。

### 能力成長は入れない。生存力の器は装備の防御で作る

決定事項。プレイヤーの能力値(VIT/STR等)はレベルで成長させない。ロール感は装備とスキルの選択で出し、能力は
装備で変動させる。Elona式のスキル連動能力成長は採らない。理由は下の「採用しなかった方法」に記す。

この制約下でも後半の緊張は作れる。鍵は装備の**防御**が per-hit を緩和する点。ダメージは
`max(base - defense, MinDamage)` なので、敵の絶対ダメージを大きくしても、防御を積んだ想定プレイヤーには
緩和されて多ターンの消耗になる。一方、無装備の床には即死級で刺さる。防御バフが「床は即死・想定は消耗」を
分ける窓を作る。HPを増やさずとも、被弾耐性の器で緊張の土俵ができる。

### 案1の設計。想定装備トラック + 敵の絶対ダメージスケール

2つを組で入れる。片方だけでは効かない。

1. **想定装備トラック**。進行に沿って想定プレイヤーが持つ防御(と装備由来HP)をモデル化する。スキルの
   `SkillLevelAfterAttacks` と同様に、日→想定防御の写像を1本置く。`balance/progression.go` の想定プレイヤーに、
   スキル倍率に加えて防御値を持たせ、`ProgressionCurve` が床(無装備)と想定(装備込み)を並べる。防御の写像は
   行動依存の設計仮説で、`DefaultAttacksPerDay` と同じ扱い。
2. **敵の絶対ダメージを進行でスケール**。高危険度の敵の武器ダメージを引き上げ、装備防御で緩和されても想定
   プレイヤーに複数ターンで効く水準にする。床には即死級になるが、床はハードモードとして許容する。強化量は
   交換レートと進行カーブで、想定 day20 死亡確率を目標(例 5〜8%)へ寄せるよう逆算する。

床を基準から外すわけではない。床は「無装備・無成長なら後半は生き残れない」という下限として温存し、設計の
主基準は想定プレイヤーの進行カーブに移す。approach.md の静的下限の位置づけを「survivability は装備で伸びる」
前提へ更新する。

`auto` は敵ダメージのスケール量に人の判断が要るので `needs-decision`。方針すなわち能力固定・装備防御で器を
作る・敵絶対ダメージで締めるは合意済みなので `status: accepted`。

## 採用しなかった方法

- coeffWeaponDamage を下げる(方向B単独)。上表の通り効果が小さく手応えを損なうため見送り。
- 敵ダメージ/HPの一律強化(方向A単独)。床が即死地獄になり survivability 要件を破るため見送り。防御バフの器を
  先に作らずに絶対ダメージだけ上げると床が壊れる。案1は装備防御トラックとセットにしてこれを回避する。
- 敵をグラスキャノン化(高ダメージ低HP)。想定を脅かせるが床は確実に全滅するため不採用。
- Elona式のスキル連動能力成長。計画的なロール感を装備とスキルで出すという設計意図と衝突する。創発・grind・
  意図からのドリフトが planned build を崩す。加えて能力成長は power ceiling を上げ、後半緩化を悪化させる方向で、
  緊張回復にはむしろ逆行する。能力は固定のまま装備で変動させる現状を維持する。
- 静的下限を完全に捨てる(元の案2)。床は無装備・無成長の下限として温存する価値があるので廃止しない。主基準を
  想定プレイヤーへ移すが、床も並べて両方を見る。案1に吸収した。

## 想定装備トラックの実装と、敵チューニングの前提

想定装備トラックは実装した。`progression.go` の `ExpectedGearDefenseAtDay` が日→想定防御(上限+16)を返し、
`ProgressionCurve` が床(無装備)と想定(装備防御込み)を並べる。baseline.md の進行カーブに想定防御列が載る。

その上で敵の絶対ダメージスケールを計測した。後半専用の敵(veteran_husk・razor_hound・fireball・blue_beast・
blue_figure、minDanger>=5)の STR を +22 すると、想定プレイヤーの後半死亡は 0%→3〜7%(5%近傍)へ回復し、
早期・中盤は無傷にできる。武器は bite/tackle 等が全敵と共有なので STR を上げるのが唯一の非波及レバー。

ただしこの敵強化は**床基準の目標体系と衝突する**ことが判明した。STR+22 で床の day20 戦力比は 1.22→0.76、
死亡は 25%→56% へ落ち、`TargetPowerRatio`(day20=1.3)・`metricBands` の戦力比帯[1.1,1.9]・`SolveScalar` の
目標探索がいずれも破綻する。さらに STR は member 単位なので森・洞窟の同名敵にも波及する。

結論。敵チューニングを入れる前に、**難易度目標を床基準から想定プレイヤー基準へ作り替える**必要がある。
`TargetPowerRatio`・`DifficultyCurve` の 内/外 判定・戦力比帯を想定プレイヤーの進行カーブに対して定義し直し、
床は「無装備ハードモード」として目標帯の外にあることを許容する形にする。これは別の作業単位。敵STRバフ単独は
差し戻し、目標体系の作り替えを先行タスクとする。

## コメント

計測がA・Bの限界を先に証明したので、投機的な定数いじりを避けられた。方針は案1に確定した。能力は固定のまま
装備防御で生存力の器を作り、敵の絶対ダメージを進行でスケールさせる。防御が per-hit を緩和するので、床即死級の
敵ダメージでも装備した想定プレイヤーには多ターン消耗になる、という非対称が設計の核。想定装備トラックまで実装し、
敵チューニングは床基準の目標体系を想定基準へ作り替えてから入れる、という順序が計測で確定した。
