# レビュー対応

- 指摘は中身で判断する。同じ指摘が繰り返されたことは、直す理由にならない。読み違いや計算の誤りは、根拠を添えて対応しない。
- description に `## レビュー対応` の節を置き、対応した項目も対応しない項目も、理由付きで表に行を足していく。前の回の行は消さない。

  ```markdown
  ## レビュー対応

  | 指摘 | 対応 | 理由 |
  |---|---|---|
  | 屋内が屋外より明るくなりうる | 直した | 日照で頭打ちにし、テストに行を足した |
  | 底上げの倍率まで vision で計算する | 対応しない | 描画の調整値が視界の計算へ漏れる |
  ```

- GitHub へのコメントでは返さない。対応の記録は description だけに残す。
- description を書き換えてから push する。push で claude-review が走り直し、そのとき description も読むので、判断の経緯を踏まえたレビューになる。
